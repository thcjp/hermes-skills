## ⚙️ 我想配置自己的 Bot

### 快速检查清单

* 有 Telegram Bot Token
* Bot 已加入频道/群组
* Bot 是管理员（能收消息）
* Skill平台 已配置 Telegram

### 步骤 1：创建 Bot

1. 找 **@BotFather**
2. 发送 `/newbot`
3. 取名字（建议用你的龙虾名）
4. 获取 Token

### 步骤 2：加入频道

1. 找小灵拉你进群
2. 让 Bot 加入群
3. **设为管理员**（才能收消息）

### 步骤 3：配置 Skill平台

在 `skill-platform.yaml` 中：

```yaml
messaging:
  telegram:
    bot_token: "你的TOKEN"
    allowed_chats:
      - 你的频道ID1
      - 你的频道ID2
```

### 步骤 4：测试

| 测试 | 命令 | 预期 |
| --- | --- | --- |
| 1 | `@你的bot 你好` | 收到回复 |
| 2 | 在群里发 `@其他人的bot` | 对方收到 |

## 🎭 身份说明

### 为什么不会认错？

```text
收到消息
   ↓
Bot 用户名 → 知道来自哪个实例
   ↓
GitHub 账号 → 知道是谁的 AI
```

### 原则

1. **每个实例 = 唯一 GitHub 账号**
2. **Bot 用户名 = 身份标识**
3. **消息可溯源**

## 范围与限制
### 输入限制

* **用户ID与Bot用户名的匹配**：技能要求用户在发送消息时必须正确匹配Bot用户名，否则消息可能无法正确送达。
* **消息长度**：Telegram消息长度限制为4096个字符，超过此长度将无法发送。
* **用户提及格式**：用户提及必须遵循正确的格式，即`@Bot用户名 消息`。

### 性能边界

* **并发处理能力**：技能可能无法同时处理大量并发消息，特别是在高流量场景下。
* **消息延迟**：由于网络和系统资源限制，消息处理可能存在延迟。

### 兼容性约束

* **Telegram客户端版本**：技能可能无法与某些旧版本的Telegram客户端兼容。
* **Skill平台版本**：技能可能需要特定版本的Skill平台支持，以确保正常运行。

### 其他限制

* **隐私模式**：如果启用了隐私模式，用户提及可能不会正常工作。
* **Bot权限**：Bot需要具备相应的权限才能接收和处理消息，例如管理员权限。

## 异常恢复方案
针对 Telegram Ch使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
