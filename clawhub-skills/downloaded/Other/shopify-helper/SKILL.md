# Shopify Helper

Shopify建站助手。店铺搭建、主题定制、产品管理、SEO优化、应用推荐、上线检查。Shopify store builder with setup, theme, product, SEO, apps, launch checklist. Shopify、独立站、DTC品牌、电商建站。Use when building or optimizing Shopify stores.

## 如何使用

1. 选择你需要的功能命令
2. 输入你的具体需求描述
3. 获取专业的输出结果
4. 根据需要调整和完善

## 命令速查

```text
  setup           setup
  theme           theme
  product         product
  seo             seo
  app             app
  launch          launch
```

## 专业建议

* 店铺搭建 (setup)**: 按流程一步步设置，别跳步骤
* 主题定制 (theme)**: 先选好主题再定制，减少返工
* 产品管理 (product)**: 产品图片+描述是核心竞争力
* SEO优化 (seo)**: 建站初期就要考虑SEO
* 应用推荐 (app)**: 别装太多APP，影响速度

## 边界条件与限制

### 输入限制
- **输入长度**：Shopify Helper技能对输入文本长度有限制，建议输入长度不超过500字，以确保处理效率和准确性。
- **输入格式**：输入文本应遵循Markdown格式，避免使用特殊字符或格式，以免影响技能的正常处理。
- **关键词限制**：输入中应包含至少一个触发关键词，如“店铺搭建”、“主题定制”等，以便技能能够识别并执行相应功能。

### 性能边界
- **并发处理**：Shopify Helper技能在同一时间只能处理一个请求，高并发场景下可能会出现排队等待的情况。
- **响应时间**：技能的响应时间受网络延迟和底层模型能力影响，通常在几秒内完成。

### 兼容性约束
- **操作系统**：Shopify Helper技能在Windows、macOS和Linux操作系统上均可运行，但要求Agent平台支持SKILL.md。
- **LLM支持**：技能依赖于LLM API，无LLM环境无法使用。
- **API限制**：技能使用的外部API可能存在调用频率限制，请遵守API提供商的规定。

### 数据隐私
- **数据安全**：Shopify Helper技能在处理过程中会收集和存储用户输入数据，请确保输入数据的安全性，避免泄露敏感信息。
- **数据使用**：技能会根据用户输入提供相应的建议和操作，不会将用户数据用于其他目的。

2. **通用电商工具**：虽然市面上有许多通用的电商工具，但它们往往功能较为分散，需要用户在不同工具间切换，操作复杂。Shopify Helper则是一个集成的解决方案，涵盖了店铺搭建、主题定制、产品管理、SEO优化等多个方面，提供一站式服务，简化了操作流程。

3. **其他AI辅助工具**：其他AI辅助工具可能专注于特定功能，如SEO优化或产品管理，而Shopify Helper则是一个全面解决方案，能够满足从店铺搭建到上线检查的全方位需求。

### 独特功能

1. **AI辅助的SEO优化**：Shopify Helper利用AI技术，提供个性化的SEO优化建议，帮助店铺快速提升搜索排名。

2. **智能主题定制**：通过分析用户需求和店铺特点，Shopify Helper能够推荐最适合店铺的主题，节省用户筛选和定制主题的时间。

3. **自动化的产品管理**：Shopify Helper能够自动处理产品库存、价格和描述，减少手动操作，提高效率。

4. **智能应用推荐**：根据店铺需求和用户行为，Shopify Helper能够推荐最适合店铺的应用，帮助用户扩展功能。

5. **一键上线检查**：Shopify Helper提供一键式的上线检查功能，确保店铺在上线前没有遗漏任何问题。
