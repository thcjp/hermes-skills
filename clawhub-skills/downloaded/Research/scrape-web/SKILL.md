# Scrape Web

使用 Scrapling 获取网页内容，返回纯文本或选择器结果。

## 依赖说明

```bash
pip install "scrapling[all]"
scrapling install
pip install httpx
```

## 依赖版本和兼容性说明

Scrape Web的依赖版本和兼容性如下：

- **Python**: Python 3.6或更高版本。
- **scraping**: 应与Python版本兼容，建议使用最新版本。
- **httpx**: 应与Python版本兼容，建议使用最新版本。

## 用法

### 1) 直接抓取纯文本

```bash
python scripts/scrape_web.py --url "https://example.com"
```

### 2) 使用 CSS 选择器

```bash
python scripts/scrape_web.py --url "https://example.com" --selector "title::text"
```

### 3) 保存到文件

```bash
python scripts/scrape_web.py --url "https://example.com" --out "output.txt"
```

## 详细的功能列表

Scrape Web提供了以下详细功能列表，包括边界条件处理：

- **抓取纯文本内容**：从指定URL获取整个网页的纯文本内容。
- **使用CSS选择器**：根据提供的CSS选择器提取网页中特定元素的内容。
- **保存到文件**：将抓取结果保存到指定的文件中。
- **输出格式**：支持纯文本和JSON两种输出格式。
- **错误处理**：自动识别和处理常见的网络错误、配置错误和选择器错误。
- **边界条件**：处理空URL、无效选择器、无响应网站和文件保存错误等边界情况。

## 参数描述

### 参数描述

- **--url**：指定要抓取的网页URL。这是必需的参数。
- **--selector**：指定要提取的CSS选择器。如果未指定，默认为整个网页的纯文本内容。
- **--out**：指定输出文件的路径。如果未指定，结果将打印到控制台。
- **--format**：指定输出格式，可以是'plain'（纯文本）或'json'（JSON格式）。默认为'plain'。

## 输入输出参数说明

以下是Scrape Web的输入输出参数说明，包括默认值、类型和取值范围：

- **--url**: 指定要抓取的网页URL，类型为字符串，必需。
- **--selector**: 指定要提取的CSS选择器，类型为字符串，可选，默认为整个网页的纯文本内容。
- **--out**: 指定输出文件的路径，类型为字符串，可选，默认将结果打印到控制台。
- **--format**: 指定输出格式，类型为字符串，可选，默认为'plain'，支持'plain'和'json'两种格式。

## 错误码定义和处理方案

Scrape Web定义了以下错误码及其处理方案：

- **错误码 100**: URL无效或无法访问，处理方案为检查URL是否正确，并确保网络连接正常。
- **错误码 101**: CSS选择器无效，处理方案为检查选择器是否正确，并确保选择器语法正确。
- **错误码 102**: 网络错误，处理方案为检查网络连接，并重试操作。
- **错误码 103**: 文件保存错误，处理方案为检查文件路径是否正确，并确保有足够的权限写入文件。

## 边界条件

### 边界条件

- **空URL**：如果提供的URL为空或无效，Scrape Web将返回一个错误消息。
- **无效选择器**：如果提供的CSS选择器无效，Scrape Web将无法提取数据，并返回一个错误消息。
- **无响应网站**：如果目标网站无响应或拒绝连接，Scrape Web将返回一个错误消息。
- **文件保存错误**：如果无法将结果保存到文件中，Scrape Web将返回一个错误消息。
