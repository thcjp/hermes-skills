# Free Weather API

## 概述

Free Weather API是一个提供全球范围内城市或地区天气预报服务的API接口。它支持实时天气查询和未来多日预报，并提供包括温度、天气状况、降水概率、风力风向等详细信息。本服务适用于各种场景，如出行规划、活动安排等。

## 功能描述

### 实时天气查询

用户可以通过指定城市或地区名称，获取该地区的实时天气信息，包括：

- 温度
- 天气状况
- 降水概率
- 风力风向
- 湿度
- 能见度

### 未来多日预报

用户可以通过指定城市或地区名称和预报天数，获取该地区未来多日（1-7天）的天气预报，包括：

- 每日最高温度和最低温度
- 天气状况
- 降水概率
- 风力风向

## 使用方法

### 输入参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| location | 字符串 | 指定查询的城市或地区名称 |
| days | 整数 | 指定预报天数，默认为1天 |
| details | 布尔值 | 是否返回详细信息，默认为true |

### 调用示例

```text
curl -X GET "https://api.free-weather.com/weather" -d "location=北京&days=3&details=true"
```

### 返回结果

API返回结果为JSON格式，包含以下字段：

- location：查询的城市或地区名称
- query_time：查询时间
- current：实时天气信息
- forecast：未来多日预报信息

## 边界条件与限制

### 输入限制

- **城市或地区名称**：输入的城市或地区名称必须符合API的命名规范，通常为全称或常用简称。不正确的名称可能导致API无法识别或返回错误信息。
- **预报天数**：预报天数参数`days`的有效范围是1到7天。超出此范围将返回错误。
- **详细信息**：`details`参数为布尔值，只能取`true`或`false`。不正确的值可能导致返回的数据不完整或不正确。

### 性能边界

- **查询频率**：由于API的免费使用限制，用户每月的查询次数可能有限制。频繁的查询可能导致账户被限制或暂停服务。
- **响应时间**：API的响应时间依赖于网络条件和服务器负载，通常在几秒内完成。但在高负载情况下，响应时间可能会延长。

### 兼容性约束

- **API版本**：目前只支持`1.0.0`版本的API，不支持旧版本或未来版本。
- **操作系统和浏览器**：API调用不依赖于特定的操作系统或浏览器，但需要确保使用的环境支持HTTPS协议。
- **数据源**：部分地区的天气预报信息可能由于数据源的限制而无法提供详细预报。

### 其他限制

- **数据准确性**：预报数据基于模型计算，存在一定的预测误差，特别是在极端天气情况下。
- **语言支持**：API目前只支持英文接口，不支持其他语言。

## 安全与隐私

### 数据安全

- **HTTPS协议**：API使用HTTPS协议进行数据传输，确保用户数据在传输过程中的安全。
- **API Key保护**：用户需要妥善保管API Key，防止未授权访问。

### 隐私政策
