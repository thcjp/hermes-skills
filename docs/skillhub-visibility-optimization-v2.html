4.1 API 方法可用性清单

GET /api/v1/orgs/862/admin/skills 可用
获取组织下所有技能的管理员视图，含审核状态、版本信息等。
GET /api/v1/skills/{slug} 可用
获取单个技能的公开详情，含所有元数据字段。本报告字段审计基于此 API。
DELETE /api/v1/orgs/862/admin/skills/{slug} 可用（已验证）
删除指定技能。已实测验证可成功删除，支持"删除后重新上传"修复策略。
PUT /api/v1/orgs/862/admin/skills/{slug} 不可用
CORS 限制或方法不允许，无法直接更新已存在技能的字段。需通过删除+重新上传实现字段更新。
POST /api/v1/orgs/862/skills 可用
上传新 skill。重新上传时需携带完整字段（tags / summary_zh / category / subCategories / changelog 等）。

4.2 字段更新策略

⚠
PUT 不可用 → 采用"删除 + 重新上传"策略
由于 PUT 方法不可用，无法直接更新已存在技能的 tags、iconUrl、summary_zh 等字段。修复方案：使用已验证可用的 DELETE 删除原 skill，再通过 POST 重新上传携带完整字段的新版本。该策略要求重新上传时务必一次性填充所有缺失字段，避免反复操作。
步骤 1
DELETE 删除原 skill
调用 DELETE API 移除字段不完整的旧版本
步骤 2
补全元数据字段
在 SKILL.md / 上传 payload 中填充 tags、summary_zh、iconUrl、changelog 等字段
步骤 3
POST 重新上传
通过 POST API 上传携带完整字段的新版本
步骤 4
等待管理员审核
新版本进入审核队列，需批量审批通过
