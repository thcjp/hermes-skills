## 依赖关系总览

```
任务1（存量治理）        任务2（金融生产）       任务3（平台治理）
  1-1 构建评分器 ←────── 前置依赖（任务2的质检依赖评分器）
  1-2 全量扫描            2-1 多源采集           3-1 全量评分同步
  1-3 低分重做            2-2 定价升级           3-2 低分识别
  1-4 上传跟踪            2-3 差异化生产          3-3 批量升级
  1-5 平台二次治理         2-4 质检重做           3-4 重传循环
  1-6 体系校准            2-5 全平台上传
                          2-6 评分跟踪
                          2-7 流程验证
```

**执行顺序**: 1-1 → (1-2 ∥ 2-1 ∥ 2-2) → (1-3 ∥ 2-3) → (1-4 ∥ 2-4 ∥ 3-1) → (1-5 ∥ 2-5 ∥ 3-2) → (2-6 ∥ 3-3) → (1-6 ∥ 2-7 ∥ 3-4)
