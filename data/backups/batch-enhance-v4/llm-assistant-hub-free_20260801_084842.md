# LLM助手中枢（基础版）

将冗长的文档转化为更清晰的推理和更干净的决策。基础版提供分层分析与假设检测能力，针对中等长度文档（5000字以内）的推理优化.
## 输入格式

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| input | string | 是 | LLM助手中枢处理的输入数据或指令 |
| options | object | 否 | 附加配置选项,如模式选择、格式偏好等 |
| callback_url | string | 否 | 异步处理完成后的回调通知URL |

## 核心能力

- **分层分析策略**：按文档长度选择分析层级——L0快速扫描（识别文档类型/结构/敏感性，低成本）→ L1深度分析（映射论证结构/识别假设/检测矛盾，中成本）。文档<5000字执行L0+L1一次完成。每层输出独立报告，支持按需跳过层级控制成本.
- **假设检测框架**：将假设分为三类——显式假设（文档明确陈述的前提）、隐式假设（未明说但论证依赖的前提）、缺失假设（需要但文档未涉及的）。配套基础检查清单：未定义术语/范围边界/决策逻辑/事实推断与建议分离。缺失假设标记为最高风险等级.
- **结构化输出**：输出包含文档评估、核心逻辑、风险薄弱点、建议下一步四段式报告。风险条目以警告标记标注，便于快速定位关键问题.

## 使用流程

### 领先步：解析上下文

提取文档类型（合同/备忘录/提案/政策）、目标受众、支持的决策、主要义务/主张/请求、敏感性等级。确认分析意图（审查/诊断）.
### 第二步：执行分层分析

L0快速扫描：识别文档类型与受众 → 提取主要标题与结构 → 标记关键义务/主张/请求 → 评估敏感性.
L1深度分析：映射论证结构与逻辑流 → 识别显式与隐式假设 → 检测歧义/矛盾/未定义术语 → 标记风险信号.
### 第三步：假设检测与输出

对照基础检查清单逐项验证假设，缺失假设标记为最高风险。输出四段式结构化报告.
## 错误处理

| 错误类型 | 原因 | 处理方式 |
|:-----|:-----|:-----|
| 分析遗漏关键内容 | 一次性处理超长文档（>5000字）导致上下文衰减 | 基础版仅支持5000字以内文档一次完成分析；超长文档请升级到付费版使用分块处理 |
| 假设检测不完整 | 未使用检查清单，仅凭直觉识别假设 | 逐项执行基础检查清单，缺失假设必须标记为最高风险等级 |
| 法律确定性误判 | 模型对不确定的法律含义编造信心 | 明确标记不确定性，不编造法律或商业确定性，建议升级到专业法务确认 |

## FAQ

**Q1：基础版支持多长的文档？**
A：基础版推荐处理5000字以内的文档，可一次完成L0+L1分析。超过5000字的文档建议升级到付费版，支持分块处理与L2聚焦深挖.
**Q2：假设检测包含哪些检查项？**
A：基础版包含4项检查：未定义术语/范围边界/决策逻辑/事实推断与建议分离。如需完整的7项检查清单（含风险转移/结构性混淆/显式隐式区分），请升级到付费版.
**Q3：基础版支持版本比对吗？**
A：基础版不支持差异化文档比对。如需对比两个版本的文档差异并评估影响，请升级到付费版获取差异化比对能力.

## 已知限制

1. **文档长度受限**：基础版仅支持5000字以内文档一次完成分析，不支持分块处理与跨块全局检查.
2. **假设检测项有限**：仅包含4项基础检查，缺少风险转移/结构性混淆/显式隐式区分3项高级检查.
3. **无差异化比对**：不支持多版本文档比对与差异分析.
## 升级提示

本基础版提供分层分析与基础假设检测能力。升级到付费版可解锁以下高级能力：

- **L2聚焦深挖**：深入高风险区域分析，交叉引用相关条款，生成具体修复建议
- **文档分块处理**：支持超长文档（>50000字）按章节逻辑边界分块，逐块独立分析后全局检查跨块矛盾，解决上下文衰减
- **完整7项假设检测清单**：新增风险转移检测/结构性混淆检测/显式隐式区分三项高级检查
- **结构化压缩**：保留风险信号，压缩背景与重复内容，节省40-60%输出token
- **差异化文档比对**：版本识别→分块对应→差异识别→影响评估→风险标记→汇总报告，仅分析差异可节省60-80%token
- **护栏机制**：对不确定的法律含义明确标记不确定性，不编造商业或法律确定性

升级后可处理50页以上合同审查、80000字政策文件压缩、多版本合同比对等复杂长文档场景.

## 分层分析策略细化

为了更好地说明分层分析策略的细节，以下是针对L0快速扫描和L1深度分析的具体步骤和目的的补充说明：

- **L0快速扫描**：首先进行文档类型和结构的快速识别，以便快速了解文档的整体布局和内容层次。此步骤旨在减少后续分析的复杂性，提高效率。
- **L1深度分析**：在快速扫描的基础上，进一步分析文档的逻辑结构和论证过程，识别文档中的关键假设和潜在的逻辑矛盾。

## 假设检测框架扩展

假设检测框架的详细说明，包括不同类型假设的定义和识别方法：

- **显式假设**：通过直接阅读文档内容，识别出明确陈述的前提条件。
- **隐式假设**：通过分析文档的上下文和逻辑推理，识别出未明确陈述但论证依赖的前提条件。
- **缺失假设**：通过分析文档的论证结构，识别出需要但文档中未涉及的前提条件。
