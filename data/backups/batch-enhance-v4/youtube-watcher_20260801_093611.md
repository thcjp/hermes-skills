## Functional Details and Boundary Conditions

### Core Function Details

1. **Extraction of YouTube video subtitles**
   - **Input Parameters**: Video URL
   - **Processing Logic**: Call YouTube data services through API to obtain video subtitle information, and then parse and extract it
   - **Output Result**: Subtitle text content

2. **Reading subtitle text**
   - **Input Parameters**: Subtitle text content
   - **Processing Logic**: Parse the subtitle text and extract key information such as timestamps and dialogue content
   - **Output Result**: Structured data for further processing and analysis

3. **Subtitle text search**
   - **Input Parameters**: Keywords or questions
   - **Processing Logic**: Search the subtitle text for keywords or questions, return matching results
   - **Output Result**: List of matching results

4. **Subtitle text summarization**
   - **Input Parameters**: Subtitle text content
   - **Processing Logic**: Summarize the subtitle text and extract the main content and key information
   - **Output Result**: Summary text

### Boundary Conditions

1. **Input video URL limit**: Only supports YouTube platform video URLs
2. **Subtitle text length limit**: The length of a single subtitle text does not exceed 10,000 characters
3. **Concurrency request limit**: The number of requests initiated simultaneously by a single user does not exceed 5
4. **API call frequency limit**: The number of API calls per hour for a single user does not exceed 100
5. **Character encoding requirements**: Subtitle text encoding format is UTF-8
6. **Network connection requirements**: Ensure a stable network connection, otherwise requests may fail
7. **Subtitle parsing accuracy**: Due to the variability in YouTube subtitle quality, parsing accuracy may be affected
8. **Subtitle text format**: Input subtitle text format is plain text, does not support rich text format

### Error Handling

1. **Video URL error**: The input YouTube video URL does not exist or the format is incorrect
   - **Handling Method**: Prompt the user to enter a correct video URL

2. **Subtitle parsing failure**: Errors occur during subtitle text parsing
   - **Handling Method**: Prompt the user to check the format of the subtitle text or contact technical support

3. **Network connection exception**: Network connection issues occur during the request
   - **Handling Method**: Retry the request or prompt the user to check network connection

4. **API call limit**: Exceeds API call frequency limit
   - **Handling Method**: Prompt the user to wait for a period of time and then try again

5. **Input parameter error**: Input parameters do not meet the requirements
   - **Handling Method**: Prompt the user to enter the correct parameters

6. **System error**: Internal server error causes the request to fail
   - **Handling Method**: Prompt the user to retry after a while or contact technical support

7. **Subtitle text is empty**: The input subtitle text is empty
   - **Handling Method**: Prompt the user to enter non-empty subtitle text

8. **Search results are empty**: There are no matches for the search keywords or questions in the subtitle text
   - **Handling Method**: Prompt the user to check if the keywords or questions are correct
