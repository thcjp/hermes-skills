## 错误处理

| 错误场景 | 业务码 | 原因分析 | 处理方式 |
|:------:|--------|:-------|:------:|
| 参数缺失 | `1001` | 必填参数未传 | 检查请求参数表,补全必填项 |
| 未授权 | `2001` | `Authorization: Bearer` 头缺失 | 重新获取 token 后检查网络连接和配置后重试 |
| 资源不存在 | `3001` | 请求的资源 ID 不存在 | 核实资源 ID 是否正确 |
| 服务器错误 | `5001` | 服务端处理异常 | 联系后端排查日志 |
| 功能不可用 | — | 需要高级功能（安全建议、变更记录等） | 升级付费版解锁 |
