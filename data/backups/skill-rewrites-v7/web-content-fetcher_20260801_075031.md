以下是"web content fetcher 4"的返回值数据结构：


字段含义：

    - **template_used**: 模板名称。
    - **word_count**: 字数统计。
    - **style**: 输出风格。
- **error**: 错误信息，当请求失败时返回。

### 代码示例

以下为使用"web content fetcher 4"获取网页内容的代码示例：

```python
import requests

def fetch_webpage(url, service='jina', content_type='text', style=''):
    response = requests.get(f'https://{service}.new/{url}')
    if response.status_code == 200:
        data = response.json()
        if data['success']:
            return data['data']['result']
        else:
            return data['error']
    else:
        return '请求失败'

# 使用示例
url = 'https://example.com'
result = fetch_webpage(url)
print(result)
```

以上代码展示了如何使用"web content fetcher 4"获取网页内容，并打印结果。
