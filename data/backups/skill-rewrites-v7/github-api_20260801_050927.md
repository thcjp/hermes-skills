## 错误处理
| Status | Meaning |
|:-----:|:-----:|
| 400 | Missing GitHub connection |
| 401 | Invalid or missing Maton API key |
| 403 | Forbidden - insufficient permissions or scope |
| 404 | Resource not found |
| 408 | Request timeout (common for complex searches) |
| 422 | Validation failed |
| 429 | Rate limited |
| 4xx/5xx | Passthrough error from GitHub API |

### 错误恢复步骤
**CLI:**

1. Check your auth state:

```bash
maton whoami
```

2. Verify the API key is valid by listing connections:

```bash
maton connection list
```

**Manual:**

1. Check that the `MATON_API_KEY` environment variable is set:

```bash
echo $MATON_API_KEY
```

```bash
python <<'EOF'
import urllib.request, os, json
req = urllib.request.Request('https://api.maton.ai/connections')
req.add_header('Authorization', f'Bearer {os.environ["MATON_API_KEY"]}')
print(json.dumps(json.load(urllib.request.urlopen(req)), indent=2))
EOF
```

### JavaScript
```javascript
const response = await fetch(
  'https://api.maton.ai/github/repos/owner/repo/issues?state=open&per_page=10',
  {
    headers: {
      'Authorization': `Bearer ${process.env.MATON_API_KEY}`
    }
  }
);

```

### Python
```python
import os
import requests
# ...
response = requests.get(
    'https://api.maton.ai/github/repos/owner/repo/issues',
    headers={'Authorization': f'Bearer {os.environ["MATON_API_KEY"]}'},
    params={'state': 'open', 'per_page': 10}
)
issues = response.json()
```

## 边界条件与限制

### 输入限制
- **API Key有效期限**: 用户的API Key有效期限有限，过期后需要重新生成或更新。
- **请求频率限制**: GitHub API对请求频率有限制，超过限制会导致请求被拒绝。需要合理规划请求频率以避免被限制。
- **数据大小限制**: 对于某些操作，如文件上传或下载，存在数据大小的限制，超过限制将无法完成操作。

### 性能边界
- **并发请求处理**: 技能可能无法同时处理大量并发请求，尤其是在高负载情况下。
- **响应时间**: 在高峰时段，技能的响应时间可能会延长。

- **GitHub版本兼容性**: 技能可能需要与特定版本的GitHub API兼容，不同版本的API可能存在差异。

- **权限申请**: 使用技能时需要申请相应的GitHub API权限，权限范围需符合实际操作需求。
- **敏感操作限制**: 对于敏感操作，如修改或删除仓库内容，需要用户手动确认或具备相应权限。
