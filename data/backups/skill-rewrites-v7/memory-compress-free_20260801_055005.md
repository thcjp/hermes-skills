## 故障排除 (Troubleshooting)

在使用日志压缩器免费版时，可能会遇到一些问题。以下是一些常见的故障排除步骤：

### Node.js 运行时缺失
- **症状**：执行压缩脚本时出现错误，提示 Node.js 未安装或版本过低。
- **解决方法**：安装 Node.js 16+ 版本，可以通过 Node.js 官网下载安装包。

### 输出目录不存在
- **症状**：执行压缩脚本时，输出文件路径所在目录不存在。
- **解决方法**：手动创建输出目录，可以使用 `mkdir -p` 命令。

### 压缩比为 1（未压缩）
- **症状**：压缩后的文件大小与原始文件大小相同。
- **解决方法**：检查日志文件是否已高度结构化，如果是，则这是正常现象。

### 日志文件格式错误
- **症状**：压缩脚本无法处理日志文件，或输出格式不正确。
- **解决方法**：检查日志文件格式是否为 Markdown，并确保内容没有语法错误。

### 系统资源不足
- **症状**：处理大文件时，系统资源不足导致脚本崩溃。
- **解决方法**：关闭不必要的后台程序，释放系统资源。
