```bash
  --header "Authorization: Bearer $TAVILY_API_KEY" \
```

### Advanced Search

```bash
curl --request POST \
```

## 功能详解与边界条件

### 核心功能详解

1. **搜索功能**：
   - **输入参数**：`query`（查询字符串），`max_results`（最大结果数），`topic`（主题），`time_range`（时间范围），`include_domains`（包含的域名），`search_depth`（搜索深度），`chunks_per_source`（每个源的内容块数），`include_raw_content`（是否包含原始内容）。
   - **处理逻辑**：通过Tavily的LLM优化搜索API，对输入的查询参数进行处理，返回相关结果和片段。
   - **输出结果**：JSON格式，包含`success`（是否成功），`data`（搜索结果），`metadata`（元数据）。

2. **大数据集流式处理**：
   - **输入参数**：与搜索功能相同。
   - **处理逻辑**：对大规模数据集进行流式处理，实时返回搜索结果。
   - **输出结果**：与搜索功能相同。

3. **多数据源关联查询**：
   - **处理逻辑**：整合多个数据源，进行跨数据源的关联查询。

4. **可视化图表自动生成**：
   - **处理逻辑**：根据搜索结果，自动生成可视化图表。
   - **输出结果**：图片格式，展示搜索结果。

5. **定时数据同步与增量更新**：
   - **处理逻辑**：定时同步数据，实现数据的实时更新。

### 边界条件

1. **输入大小限制**：查询字符串长度不超过1024个字符。
2. **字符编码要求**：支持UTF-8编码。
3. **并发限制**：单个API调用最多支持100个并发请求。
4. **搜索深度限制**：搜索深度不超过3级。
5. **结果返回时间限制**：单个API调用结果返回时间不超过5秒。
6. **数据源数量限制**：最多支持5个数据源。
7. **数据块数量限制**：每个数据源的内容块数不超过1000个。
8. **API Key限制**：每个API Key每天最多支持1000次API调用。
