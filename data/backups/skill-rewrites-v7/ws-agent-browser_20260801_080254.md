## 边界条件与限制

### 输入限制
- **URL长度**: 输入的URL长度不应超过2048个字符，超出部分将被截断。
- **参数格式**: 输入参数必须符合预定义的格式，例如，`url`参数必须是有效的URL字符串。
- **CSS选择器**: 如果使用`selector`参数，它必须是一个有效的CSS选择器，否则操作将无法定位到目标元素。

### 性能边界
- **并发操作**: 在同一时间，技能最多支持对10个不同的标签页进行操作。
- **数据抓取**: 单次抓取的数据量不宜过大，建议单个数据集的大小不超过10MB。

### 兼容性约束
- **浏览器兼容性**: 技能主要针对现代浏览器（如Chrome, Edge）进行优化，可能不兼容较老版本的浏览器。
- **操作系统兼容性**: 技能理论上应在Windows, macOS, Linux操作系统上运行，但具体表现可能因操作系统版本和配置而异。

### 其他限制
- **网络稳定性**: 网络连接不稳定可能导致操作失败或数据抓取不完整。
- **页面动态性**: 对于动态加载内容的页面，技能可能无法完全抓取所有数据，特别是那些在页面加载后通过JavaScript动态添加的内容。

## 输入格式与示例

### 输入格式
- **url**: 目标网页的URL，必须是一个有效的HTTP或HTTPS地址。
- **action**: 操作类型，如`navigate`（导航）、`screenshot`（截图）、`click`（点击）、`input`（输入）、`scroll`（滚动）或`extract`（提取内容）。
- **selector**: CSS选择器，用于指定页面上的元素。
- **value**: 输入值，用于`input`操作。
- **timeout**: 超时时间，单位为毫秒，默认为30000毫秒。

### 示例
```json
{
  "url": "https://example.com",
  "action": "screenshot",
  "selector": "#main-content",
  "timeout": 5000
}
```

在这个示例中，技能将被配置为导航到`https://example.com`，然后截图页面中ID为`main-content`的元素，并设置超时时间为5000毫秒。

## 安全与隐私

### 数据安全
- 技能不会存储或传输任何敏感数据，所有操作都是实时的，并且数据在操作完成后即被销毁。
- 对于抓取的数据，技能不会进行任何形式的持久化存储。

### 隐私保护
- 技能不会收集或记录用户的任何个人信息。
- 在使用技能进行数据抓取时，应确保遵守相关法律法规，不侵犯他人的隐私权。

## 限制与注意事项

### 限制
- 技能不支持对需要100%确定性的关键决策场景进行操作。
- 对于需要复杂逻辑判断或人工干预的场景，技能可能无法提供满意的解决方案。

### 注意事项
- 在使用技能进行自动化操作时，请确保操作符合法律法规和道德标准。
- 对于可能对用户造成影响的操作，如表单自动填写，应确保输入的数据是准确和合法的。
