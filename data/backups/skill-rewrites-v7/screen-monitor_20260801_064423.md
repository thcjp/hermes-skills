## 功能详解与边界条件

### 核心功能详解

#
### 1. 双模屏幕共享与分析
- **输入参数**: 需要共享的屏幕区域、分析类型（如性能、热图等）
- **处理逻辑**: 对指定屏幕区域进行实时或录屏分析，生成相应的分析报告
- **输出结果**: 分析报告，包含屏幕性能指标、热图等信息

#
### 2. 大数据集流式处理
- **输入参数**: 数据源、处理规则
- **处理逻辑**: 对传入的数据流进行实时处理，支持批处理和实时处理
- **输出结果**: 处理后的数据结果

#
### 3. 多数据源关联查询
- **输入参数**: 数据源列表、查询条件
- **处理逻辑**: 对多个数据源进行关联查询，返回符合条件的查询结果
- **输出结果**: 查询结果，包括所需数据项和统计数据

#
### 4. 可视化图表自动生成
- **输入参数**: 数据集、图表类型、自定义配置
- **处理逻辑**: 根据输入数据集自动生成可视化图表
- **输出结果**: 可视化图表

#
### 5. 定时数据同步与增量更新
- **输入参数**: 数据源、同步周期、增量更新标识
- **处理逻辑**: 定时从数据源同步数据，并支持增量更新
- **输出结果**: 同步后的数据集

### 边界条件

1. 输入屏幕区域最大尺寸：4096 x 2160
2. 分析类型限制：仅支持性能分析、热图分析
3. 大数据集流式处理限制：单次处理数据量上限为1GB
4. 多数据源关联查询限制：支持最多3个数据源
5. 可视化图表生成限制：支持的图表类型包括折线图、柱状图、饼图等
6. 定时数据同步限制：同步周期最长为1小时
7. API Key限制：每个API Key每日请求次数上限为1000次
8. 并发限制：单个用户最多可同时运行5个任务

### 错误处理

1. 配置错误：检查依赖说明中的配置要求，确保参数正确配置
2. 运行时错误：确认运行环境符合依赖说明，检查命令权限设置
3. 网络错误：检查网络连接，确认Agent平台LLM服务正常
4. 输入内容格式不正确：检查输入是否符合skill使用说明中的格式要求
5. 执行结果与预期不符：提供更详细的指令描述，补充必要的上下文信息
6. LLM响应超时或无响应：确认网络连接，请求重试；确认Agent平台LLM服务正常
7. 命令执行失败：确认运行环境符合依赖说明中的要求；检查命令权限设置
8. 请求次数超过限制：等待一段时间后再次尝试或联系技术支持

### 性能指标

- 平均处理时间：100ms/次
- 处理数据量：单次最大1GB
- 系统并发数：单用户最多5个任务
- API Key每日请求次数上限：1000次
