## 批量生成任务的失败重试机制

豆包图片生成专业版的批量生成任务支持失败重试机制，该机制旨在确保在遇到生成失败时能够自动重新尝试生成。具体实现如下：

- **重试次数限制**：系统默认设置重试次数为3次，但可根据用户需求进行调整。
- **重试间隔**：重试间隔默认为1分钟，但同样可以自定义。
- **重试触发条件**：当生成任务因为服务器错误、网络问题或其他不可预见的错误导致失败时，系统会自动触发重试。
- **重试策略**：系统采用指数退避策略进行重试，即每次重试的间隔时间会比上一次长，以避免短时间内对服务器造成过大压力。
- **重试日志记录**：系统会记录每次重试的详细信息，包括重试时间、失败原因、重试次数等，方便用户进行问题排查。

这些详细的重试机制描述将有助于用户更好地理解批量生成任务在遇到失败时的行为，从而在遇到问题时能够快速定位并解决问题。

## 常见问题
### Q1：专业版与免费版工作流是否兼容？
**A：** 完全兼容。专业版包含免费版所有工作流，单图生成流程可直接运行。专业版扩展的是批量、多比例、风格预设等能力.
### Q2：批量生成中部分图片失败怎么办？
**A：** 专业版自动记录失败任务：

```bash
py --retry-failed /tmp/generate-queue.json
# ...
py --resume /tmp/generate-queue.json
```

### Q3：多比例输出如何工作？
**A：** 一次提示词同时生成多种比例版本：

```bash
  --config items.json \
  --ratios "3:4,1:1,16:9"
```

每个比例版本保存到独立子目录.
### Q4：风格预设如何创建？
**A：** 通过风格管理器创建：

```bash
  --name "我的风格" \
  --keywords "简约,高质感" \
  --negative "复杂,模糊"
```

### Q5：参考图风格迁移效果如何？
**A：** 参考图风格迁移效果取决于：

- 参考图风格特征明显程度
- `style_strength` 参数（建议 0.7-0.9）
- 提示词与参考图的兼容性

### Q6：提示词增强是否支持英文？
**A：** 支持。提示词增强支持中英文输入与输出：

```bash
  --input "a cat" \
  --language "en" \
  --output /tmp/enhanced-en.txt
```

### Q7：生成结果如何自动归档？
**A：** 启用自动归档：

```bash
  --config items.json \
  --auto-archive \
  --archive-dir /images/archive/
```

按项目与时间自动组织目录结构.

## 边界条件处理

在批量生成任务中，我们考虑了以下边界条件并进行相应处理：

- **输入数据格式错误**：当输入数据格式不正确时，系统会返回错误信息，并提示用户正确的数据格式。
- **生成资源不足**：当系统资源不足以处理大量生成任务时，系统会自动排队等待，直到有可用资源。
- **网络连接中断**：当网络连接中断时，系统会自动重试任务，直到连接恢复。
- **任务超时**：当生成任务超时时，系统会自动终止任务，并返回超时错误信息。

这些边界条件的处理确保了系统在极端情况下的稳定性和可靠性。
