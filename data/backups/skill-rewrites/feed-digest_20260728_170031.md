# Feed Digest

Welcome to Feed Digest, a powerful tool designed to revolutionize the way you manage your content subscriptions and reading experience. With Feed Digest, you can effortlessly aggregate content from multiple sources and maintain a streamlined workflow, even in the face of information overload.

## Overview

Feed Digest is tailored for individuals and teams who need to stay on top of their content subscriptions efficiently. It simplifies the process of content aggregation, reading status management, and information filtering, making it an invaluable asset for professionals in marketing, advertising, and content creation.

## Workflow

To get the most out of Feed Digest, follow this structured workflow:

1. **Fetch New Content** — Use the `feed fetch` command to import the latest entries from your subscribed feeds.
2. **Scan Recent Entries** — Execute `feed get entries --limit N` to quickly review recent unread entries, complete with titles, feed sources, dates, and summaries.
3. **Triage Content** — Prioritize your content by selecting 5-10 high-priority posts based on relevance and personal interest.
4. **Read Selected Articles** — Retrieve the full post in Markdown format using `feed get entry <id>` for easy reading and editing.
5. **Synthesize and Organize** — Summarize each article in 2-3 sentences and categorize them by theme if applicable.
6. **Mark as Read** — Use `feed update entries --read <id1> <id2> ...` to update your read status for the selected entries.

## Commands Reference

```text
feed fetch                              # Fetch the latest content from all feeds
feed get entries --limit N              # List unread entries with details
feed get entries --feed <id> --limit N  # Filter entries by a specific feed
feed get entry <id>                     # Read the full post in Markdown
feed search "<query>"                   # Perform a full-text search
feed update entries --read <id> ...     # Mark entries as read
feed get feeds                          # List all feeds with unread counts
feed get stats                          # Retrieve database statistics
```

## Notes

- **Output Format**: The default output is in table format, which is optimal for quick scanning. Use `-o json` for JSON output if necessary.
- **Markdown Format**: All content is returned in Markdown format for convenient reading and editing.
- **Filtering by Feed**: Use `--feed <feed_id>` to filter entries from a specific feed when needed.
