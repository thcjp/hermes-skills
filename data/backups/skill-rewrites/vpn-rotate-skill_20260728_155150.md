## 输入输出格式详细说明

为了确保技能的易用性和准确性，以下是对输入输出格式的详细说明：

### 输入格式详细说明

| 参数名 | 类型 | 必填 | 说明 |
|---:|---:|---:|---:|
| instruction | string | 是 | 用户输入的指令文本，应包含足够的上下文信息以便技能正确执行。 |
| context | string | 否 | 可选的上下文信息，用于提供额外的背景或参数，以辅助技能的执行。 |

### 输出格式详细说明

```json
{
  "success": true,
  "data": {
    "result": "具体的结果数据",
    "status": "执行状态描述"
  },
  "error": {
    "code": "错误代码",
    "message": "错误描述信息"
  }
}
```

- `success`: 布尔值，表示操作是否成功。
- `data`: 对象，包含操作结果和状态信息。
  - `result`: 字符串，具体的操作结果数据。
  - `status`: 字符串，描述操作的状态。
- `error`: 对象，包含错误信息（仅在操作失败时存在）。
  - `code`: 字符串，表示错误的代码。
  - `message`: 字符串，描述错误的具体信息。
