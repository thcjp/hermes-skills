## Key Concepts

### Doctype and Quirks Mode
Ensure your HTML documents declare the correct `<!DOCTYPE html>` to prevent quirks mode, which can lead to inconsistent rendering across browsers.

### CSS Specificity and Cascade
Understand the cascade and specificity rules in CSS to ensure that styles are applied consistently and predictably.

### Type Coercion
Avoid type coercion issues by using strict equality (`===`) instead of loose equality (`==`).

### Async/Await and Loops
Use `for...of` loops or `Promise.all` when working with asynchronous code to manage asynchronous operations effectively.

### CORS Configuration
CORS is a server-side concern. Configure `Access-Control-Allow-Origin` headers on your server to manage CORS.

### Responsive Design
Implement responsive design using viewport meta tags and media queries to ensure your site is accessible on all devices.

### Form Handling
Prevent page reloads on form submissions by calling `e.preventDefault()` in your submit handlers.

### Image Dimensions
Specify dimensions for images to prevent layout shifts and improve CLS scores.

### HTTPS and Mixed Content
Ensure your site uses HTTPS to avoid mixed content issues and potential blocking by browsers.

### Environment Variables
Use `NEXT_PUBLIC_*` for public environment variables and keep secrets out of the client-side code.

## Common Queries

**"Make it responsive"** → Implement a mobile-first approach with CSS media queries and test on key breakpoints (320px, 768px, 1024px).

**"Deploy to production"** → Refer to the [Deployment Guide](deploy.md) for instructions on deploying to Vercel, Netlify, or a VPS.

**"Fix CORS error"** → Configure server headers or use a proxy to handle CORS if you cannot control the server configuration.

**"Improve performance"** → Use Lighthouse for audits and focus on optimizing LCP, CLS, and FID, as well as implementing lazy loading for off-screen images.

**"Add SEO"** → Optimize your site for SEO by using proper titles, descriptions, semantic HTML, OG tags, and a sitemap.xml.
