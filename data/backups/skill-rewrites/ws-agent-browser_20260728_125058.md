## 输入格式

| 参数名 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| url | string | 是 | 目标网页URL |
| action | string | 是 | 操作类型: navigate/screenshot/click/input/scroll/extract |
| selector | string | 否 | CSS选择器,用于定位页面元素 |
| value | string | 否 | 输入值,用于input操作 |
| timeout | int | 否 | 超时时间(毫秒),默认30000 |

## 异常处理

- 边界输入处理: 空输入返回提示信息, 超长输入自动截断
- 降级策略: 异常时返回默认值, 确保流程不中断

| 错误场景 | 原因 | 处理方式 |
|:---:|:---:|:---:|
| 配置错误 | 参数缺失或格式错误 | 检查依赖说明中的配置要求 |
| 运行时错误 | 运行环境不满足 | 确认运行环境符合依赖说明 |
| 网络错误 | 连接超时或不可达 | 检查网络连接后重试 |
| LLM响应超时 | 网络延迟或模型负载过高 | 增加超时时间后重试 |
| 输入格式不正确 | 用户输入不符合预期格式 | 检查输入格式,参考示例章节 |
| 执行结果与预期不符 | 指令描述不够明确 | 提供更详细的指令描述 |
| 命令执行失败 | 权限不足 | 检查命令权限设置 |
