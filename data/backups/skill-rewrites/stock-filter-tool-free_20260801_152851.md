# 股票筛选入门工具（免费版）

## 概述

本工具为个人投资者提供A股股票筛选能力。支持按基本面和技术面条件筛选股票，帮助用户从大量股票中快速找到符合条件的标的。适合个人投资者进行简单的选股分析与初步筛选.

### 筛选配置

```yaml
filter_config:
  market: a-share                # a-share | us-stock | hk-stock
  data_source: "akshare"
# ...
  defaults:
    sort_by: "roe"
    descending: true
    max_results: 50
# ...
  conditions:
    fundamentals:
      pe: { min: 0, max: 30 }
      pb: { min: 0, max: 5 }
      roe: { min: 15 }
      revenue_growth: { min: 0.1 }
      debt_ratio: { max: 0.6 }
# ...
    technical:

      rsi_period: 14
      macd: { fast: 12, slow: 26, signal: 9 }
# ...

```

## 常见问题

### Q1：免费版支持多策略组合吗？

免费版仅支持单策略筛选（多个条件AND组合）。如需多策略OR组合或复杂逻辑，建议升级PRO版.
### Q2：数据来源是什么？

免费版使用AkShare开源数据接口，数据来源包括东方财富、同花顺等公开数据。可能有延迟，仅供参考.
### Q3：支持港股和美股吗？

免费版主要支持A股筛选。美股和港股支持有限，如需完整覆盖，建议升级PRO版.
### Q4：筛选结果可以导出吗？

免费版仅支持终端展示。如需导出CSV/Excel，建议升级PRO版.

## 边界条件与限制

### 输入限制

- **条件数量**：免费版单次筛选条件不超过5个，超过此数量可能导致筛选结果不准确或工具响应超时。
- **数据类型**：输入的条件值必须是正确的数据类型，例如PE值应为数字，否则工具可能无法正确解析。
- **数据范围**：某些筛选条件（如PE、PB、ROE等）有其合理的数值范围，超出范围可能导致无结果或错误。

### 性能边界

- **响应时间**：由于数据量较大，筛选操作可能需要较长时间完成，具体时间取决于网络条件和数据源响应速度。
- **结果数量**：免费版默认最大结果数量为50条，超过此数量可能导致工具响应超时。

### 兼容性约束

- **操作系统**：工具在Windows、macOS和Linux操作系统上运行，但可能存在特定版本的兼容性问题。
- **Python版本**：工具要求Python版本为3.8或更高，不支持旧版本Python。
- **数据源**：免费版主要使用AkShare开源数据接口，该接口可能不支持所有股票市场的数据，且数据可能存在延迟。

### 数据限制

- **数据时效性**：由于数据源可能存在延迟，筛选结果中的基本面数据可能不是最新的，用户在使用时应注意数据时效性。
- **数据完整性**：免费版可能无法获取所有股票的详细数据，某些股票可能因数据缺失而无法被筛选。
