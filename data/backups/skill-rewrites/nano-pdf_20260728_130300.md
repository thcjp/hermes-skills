# Nano Pdf

## 简介

Nano Pdf是一款功能强大的PDF编辑工具，它允许用户通过自然语言指令来编辑PDF文件。这款工具基于Markdown语法，易于上手，适用于需要快速编辑PDF文件的用户。

## 快速开始

要开始使用nano-pdf，首先确保您的系统满足以下要求：

- **操作系统**: Windows, macOS, 或 Linux
- **Agent平台**: 支持SKILL.md的任意AI Agent（如Claude Code、Cursor、Codex、Gemini CLI等）

安装完成后，您可以使用以下命令来编辑PDF文件：

```bash
nano-pdf edit <file_path> <page_number> "<instruction>"
```

例如：

```bash
nano-pdf edit deck.pdf 1 "Change the title to 'Q3 Results' and fix the typo in the subtitle"
```

请注意，页面编号从0开始计数。

## 核心功能

- **自然语言指令**: 使用自然语言指令来编辑PDF文件，无需学习复杂的PDF编辑语法。
- **Markdown支持**: 基于Markdown语法，易于编写和阅读指令。
- **多平台支持**: 支持Windows、macOS和Linux操作系统。
- **集成LLM API**: 利用大型语言模型API，提高编辑准确性和效率。

## 使用场景

- **日常办公**: 快速编辑报告、合同、提案等PDF文件。
- **学术研究**: 编辑论文、会议记录等PDF文件。
- **个人学习**: 编辑学习资料、笔记等PDF文件。

### 输入

- **文件路径**: PDF文件的路径。
- **页面编号**: 要编辑的页面编号。
- **指令**: 使用Markdown语法编写的自然语言指令。

### 输出

- **编辑后的PDF文件**: 包含用户指令的PDF文件。

## 故障排查

### 错误信息

- 如果您遇到错误信息，请参考以下表格：

| 错误信息 | 原因 | 处理方式 |
|:---------|:-----|:---------|
| "Invalid page number" | 页面编号无效 | 请检查页面编号是否正确，并确保它是一个有效的整数。 |
| "Invalid instruction" | 指令无效 | 请检查指令是否使用正确的Markdown语法，并确保指令内容有效。 |
| "File not found" | 文件不存在 | 请检查文件路径是否正确，并确保文件存在于指定位置。 |

### 性能问题

- 如果您遇到性能问题，请尝试以下方法：

- **优化指令**: 使用更简洁的指令来提高编辑速度。
- **减少页面数量**: 如果可能，尝试编辑较少的页面。
- **升级Agent**: 使用更强大的Agent来提高处理速度。
