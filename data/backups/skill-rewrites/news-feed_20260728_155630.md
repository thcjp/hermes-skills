# News Feed - 实时新闻聚合工具

News Feed 是一款功能强大的新闻聚合工具，能够从 BBC、Reuters、AP、Al Jazeera、NPR、The Guardian 等主流 RSS 源中实时抓取新闻标题，为用户提供便捷的国际资讯获取途径。

## 功能概述

News Feed 提供以下核心功能：

- **多源聚合**：从多个主流 RSS 源中抓取新闻标题，覆盖全球多个地区和领域。
- **关键词过滤**：支持通过关键词过滤新闻，方便用户获取特定主题的新闻。
- **自定义输出**：允许用户自定义每个源的新闻条目数量，满足不同用户的需求。
- **Markdown 格式输出**：以 Markdown 格式输出新闻标题、摘要、发布时间和链接，方便用户直接在 Markdown 文档中使用。

## 使用指南

### 安装

确保您的系统已安装 Python 3.x 版本。您可以通过以下命令安装 News Feed：

```bash
pip install news-feed
```

### 命令行使用

News Feed 提供以下命令行命令：

#### 获取所有新闻标题

```bash
python3 news.py
```

#### 获取特定来源的新闻标题

```bash
python3 news.py --source bbc
python3 news.py --source reuters
python3 news.py --source ap
python3 news.py --source aljazeera
python3 news.py --source npr
python3 news.py --source guardian
python3 news.py --source dw
```

#### 获取特定主题的新闻标题

```bash
python3 news.py --topic "climate"
python3 news.py --source bbc --topic "ukraine"
```

#### 控制每个源的新闻条目数量

```bash
python3 news.py --limit 20
```

#### 列出所有可用来源

```bash
python3 news.py --list-sources
```

## 输出格式

News Feed 以 Markdown 格式输出新闻标题、摘要、发布时间和链接，格式如下：

```markdown
## BBC
- [标题](链接) - 摘要 - 发布时间
- [标题](链接) - 摘要 - 发布时间
- ...
## Reuters
- [标题](链接) - 摘要 - 发布时间
- [标题](链接) - 摘要 - 发布时间
- ...
```
