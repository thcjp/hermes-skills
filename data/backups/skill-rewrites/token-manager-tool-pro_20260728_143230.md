# Token用量管理工具（专业版）

## 概述

专业版在免费版的实时用量监控与省钱建议之上，扩展为面向团队与企业的完整 LLM 成本治理平台。新增定时余额监控、跨会话用量追踪、多账号统一管理、团队用量汇总与自动告警，同时与免费版的命令行语法保持向后兼容.

## 使用场景

### 场景一：团队 LLM 成本治理

团队负责人希望统一监控所有成员的 API 用量与费用.
```bash
# 添加团队成员账号
token-pro account add --name "开发者A" --provider moonshot --key-env MOONSHOT_API_KEY_A
token-pro account add --name "开发者B" --provider openai --key-env OPENAI_API_KEY_B
# ...
# 生成团队周报
token-pro team weekly --output team-report-2026-W29.md
# ...
# 示例
# 📊 团队周报（2026-W29）
# 团队总费用: ¥286.50
#   - 开发者A (Moonshot): ¥123.40
#   - 开发者B (OpenAI): ¥163.10
# 预算使用: 57.3% (¥500/¥872)
# 💡 建议: 开发者B的OpenAI用量偏高，建议部分任务切换至GPT-4o-mini
```

### 场景二：定时余额监控与告警

设置 cron 定时监控余额，低于阈值时自动告警.
```bash
# 设置定时监控（每小时检查一次）
token-pro cron add \
  --name "token-balance-check" \
  --schedule "0 * * * *" \
  --check moonshot --threshold 5
# ...
# 告警规则
# 余额 < ¥5    → 发送提醒（冷却1小时）
# 余额 < ¥1    → 发送紧急提醒（冷却30分钟）
# 24小时内3次  → 建议充值
```

```json
// 告警输出示例
{
  "alert": true,
  "balance": 3.50,
  "threshold": 5,
  "messages": {
    "cn": "🚨 [紧急] Token 管家提醒：余额 ¥3.50，低于阈值 ¥5"
  }
}
```

### 场景三：跨会话用量分析与优化

追踪多会话使用模式，生成优化建议.
```bash
# 记录会话
token-pro session record moonshot kimi-k2.5 5000 500 0.06 CNY
# ...
# 生成每日报告
token-pro session daily
# ...
# 生成每周报告
token-pro session weekly
# ...
# 智能建议
token-pro session recommend
# ...
# 输出示例
# 📊 每周用量分析
# 总会话数: 42
# 总费用: ¥56.30
# 平均会话费用: ¥1.34
# 💡 优化建议:
#   1. 周二用量峰值，建议拆分大任务
#   2. 35%的会话可用GPT-4o-mini替代，预计节省¥18/周
```

edition: pro
accounts:
  - name: 个人-Moonshot
    provider: moonshot
    key_env: MOONSHOT_API_KEY
  - name: 团队-OpenAI
    provider: openai

  enabled: true
  schedules:

    - name: daily-report
      cron: "0 9 * * *"

  levels:
    - level: warning

      cooldown: 3600
    - level: urgent

* 为每个团队成员建立独立账号档案，便于成本分摊.

## 常见问题

**Q：专业版与免费版的命令兼容吗？**
A：兼容。免费版的所有命令在专业版中可直接使用，专业版额外提供 `cron`、`session`、`team`、`account` 等子命令.
**Q：定时监控需要额外的服务吗？**
A：需要系统支持 cron 调度（Linux/macOS 自带，Windows 需使用任务计划程序）.
**Q：团队用量数据存储在哪里？**
A：所有数据存储在本地 `~/token-pro/data` 目录，不上传至任何第三方服务器.
**Q：支持多少个账号同时管理？**
A：无硬性上限，但建议单个团队不超过 50 个账号以保证监控性能.
**Q：告警支持哪些通知渠道？**
A：默认控制台输出，可配置 Webhook 通知（支持飞书、钉钉、企业微信等）.
**Q：可以与财务系统对接吗？**
A：专业版支持导出 CSV/JSON 格式的费用明细，便于与财务系统对接。直接 API 对接建议通过中间文件中转.

## 功能详解与边界条件

### 核心功能详解

1. **用量监控**：
   - **输入参数**：`--provider`（API提供商），`--account`（账户名称），`--start`（监控开始时间），`--end`（监控结束时间）
   - **处理逻辑**：查询指定账户在指定时间段的API用量数据。
   - **输出结果**：JSON格式，包含账户名称、用量、费用等信息。

2. **余额查询**：
   - **输入参数**：`--provider`（API提供商），`--account`（账户名称）
   - **处理逻辑**：查询指定账户的当前余额。
   - **输出结果**：JSON格式，包含账户名称、余额等信息。

3. **告警机制**：
   - **输入参数**：`--provider`（API提供商），`--account`（账户名称），`--threshold`（阈值），`--cooldown`（冷却时间）
   - **处理逻辑**：设置余额/用量/异常告警，当达到阈值时发送提醒。
   - **输出结果**：JSON格式，包含告警状态、余额/用量、提醒信息等。

4. **报告生成**：
   - **输入参数**：`--output`（输出文件路径），`--format`（输出格式：markdown/json）
   - **处理逻辑**：生成指定格式和内容的报告。
   - **输出结果**：生成指定格式的报告文件。

5. **多账号管理**：
   - **输入参数**：`--name`（账户名称），`--provider`（API提供商），`--key-env`（环境变量）
   - **处理逻辑**：添加/修改/删除指定账户信息。
   - **输出结果**：JSON格式，包含操作结果和账户信息。

## 差异化优势

### 与同类方案对比

Token Manager 2 与其他替代方案相比，在以下方面具有显著优势：

1. **手动操作**：手动监控和管理 Token 用量需要消耗大量时间和精力，且容易遗漏关键信息。Token Manager 2 通过自动化监控和报告生成，极大地减少了人工工作量，提高了效率。
2. **其他工具**：一些第三方工具可能提供部分 Token 管理功能，但通常缺乏跨会话分析和团队用量汇总等功能。Token Manager 2 作为一站式解决方案，涵盖了从实时监控到团队用量汇总的全流程，提供了更全面的成本治理能力。
3. **通用方法**：一些通用方法，如 Excel 或数据库，可能用于跟踪 Token 用量，但缺乏专业的分析工具和自动化功能。Token Manager 2 提供了专为此目的设计的平台，能够更好地满足团队和企业级的需求。

### 独特功能

1. **跨会话分析**：Token Manager 2 可以追踪和分析跨会话的 Token 用量，帮助用户识别高消耗操作和优化策略。
2. **团队用量汇总**：该工具能够将团队成员的用量数据进行汇总，便于团队负责人全面了解整体成本情况。
3. **自动告警**：当 Token 余额或用量达到预设阈值时，Token Manager 2 会自动发送告警通知，帮助用户及时采取措施。
4. **预算管理**：用户可以设置预算，并收到超支告警，确保成本控制。
5. **定时余额监控**：定期自动监控余额，确保用户始终了解账户状态。

### 效率提升

使用 Token Manager 2 可以带来以下效率提升：

- **节省时间**：自动化监控和报告生成功能减少了人工操作，用户可以节省大量时间。
- **减少步骤**：一站式解决方案简化了 Token 管理流程，用户无需在多个工具之间切换。

### 应用场景创新

1. **多团队协作**：Token Manager 2 支持多团队协作，方便不同团队共享资源并监控各自的成本。
2. **项目成本控制**：用户可以将 Token 用量与特定项目关联，以便于项目成本控制。
3. **智能优化**：基于跨会话分析和用量汇总数据，Token Manager 2 可以提供智能优化建议，帮助用户降低成本。
