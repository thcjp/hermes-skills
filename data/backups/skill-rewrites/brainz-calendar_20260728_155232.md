# Brainz Calendar

Efficiently manage your Google Calendar events with Brainz Calendar, a powerful command-line tool that streamlines your calendar operations.

## Overview

Brainz Calendar is designed to enhance your calendar management experience by integrating with `gcalcli`, a command-line interface for Google Calendar. It allows you to create, list, and delete events, making it an invaluable tool for anyone looking to improve their productivity and organization.

## Features

- **Create Events**: Add new events to your calendar with ease, specifying the title, date, and duration.
- **List Events**: View upcoming events within a specified date range.
- **Delete Events**: Remove events from your calendar using search terms.

## Installation

To get started with Brainz Calendar, you'll need to install `gcalcli`:

```bash
pip install gcalcli
```

## Usage

### Listing Events

List upcoming events in a specified date range:

```bash
gcalcli agenda "2026-02-03" "2026-02-10"
```

### Creating Events

Add a new calendar event:

```bash
gcalcli add --title "Team sync" --when "2026-02-04 10:00" --duration 30
```

### Deleting Events

Delete an event by search term:

```bash
gcalcli delete "Team sync"
```
