# Podcast Downloader Tool

## 简介

播客下载器工具是一款基于小宇宙平台的播客内容下载和管理工具。它能够自动下载播客音频和Show Notes，并将音频文件转换为MP3格式，以适应多种播放设备，如骨传导耳机和水下播放器。该工具旨在简化播客内容的获取和播放过程，提升用户的使用体验。

## 功能概述

### 核心功能

- **自动下载**：从小宇宙平台自动下载播客音频和Show Notes。
- **格式转换**：自动将音频文件转换为MP3格式，兼容多种设备。
- **批量下载**：支持一次性输入多个播客链接，并行下载。
- **自动下载Show Notes**：下载与播客相关的文字信息。
