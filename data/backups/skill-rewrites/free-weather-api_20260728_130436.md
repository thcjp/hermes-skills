# Free Weather API

## 概述

Free Weather API是一个提供全球范围内城市或地区天气预报服务的API接口。它支持实时天气查询和未来多日预报，并提供包括温度、天气状况、降水概率、风力风向等详细信息。本服务适用于各种场景，如出行规划、活动安排等。

## 功能描述

### 实时天气查询

用户可以通过指定城市或地区名称，获取该地区的实时天气信息，包括：

- 温度
- 天气状况
- 降水概率
- 风力风向
- 湿度
- 能见度

### 未来多日预报

用户可以通过指定城市或地区名称和预报天数，获取该地区未来多日（1-7天）的天气预报，包括：

- 每日最高温度和最低温度
- 天气状况
- 降水概率
- 风力风向

## 使用方法

### 输入参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| location | 字符串 | 指定查询的城市或地区名称 |
| days | 整数 | 指定预报天数，默认为1天 |
| details | 布尔值 | 是否返回详细信息，默认为true |

### 调用示例

```text
curl -X GET "https://api.free-weather.com/weather" -d "location=北京&days=3&details=true"
```

### 返回结果

API返回结果为JSON格式，包含以下字段：

- location：查询的城市或地区名称
- query_time：查询时间
- current：实时天气信息
- forecast：未来多日预报信息

## 安全注意事项

- 本服务使用HTTPS协议进行数据传输，确保数据安全。
- 用户需要妥善保管API Key，防止泄露。
- 用户应避免过度调用API接口，以免影响其他用户的使用。

## 常见问题

### Q1: 如何获取API Key？

A: 您可以在Free Weather API官网注册账号后获取API Key。

### Q2: 如何查询实时天气？

A: 您可以通过指定location参数查询实时天气，例如：curl -X GET "https://api.free-weather.com/weather" -d "location=北京&days=1&details=true"

### Q3: 如何查询未来多日预报？

A: 您可以通过指定location和days参数查询未来多日预报，例如：curl -X GET "https://api.free-weather.com/weather" -d "location=北京&days=3&details=true"
