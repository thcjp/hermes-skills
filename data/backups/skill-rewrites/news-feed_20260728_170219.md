# News Feed - 领先的国际新闻聚合平台

### 简介

News Feed 是一款革命性的新闻聚合工具，旨在为用户提供一个全面、高效的国际新闻资讯服务。通过整合 BBC、Reuters、AP、Al Jazeera、NPR、The Guardian 等全球知名新闻机构的 RSS 源，News Feed 实时抓取新闻标题，并提供丰富的定制化功能，满足不同用户的需求。

## 功能概述

News Feed 提供以下核心功能：

- **多源聚合**：从 BBC、Reuters、AP、Al Jazeera、NPR、The Guardian 等全球知名新闻机构中聚合新闻标题，确保用户获取全面、多元的信息。
- **关键词过滤**：用户可以通过关键词筛选新闻，聚焦特定主题，提高信息获取效率。
- **自定义输出**：用户可以根据自己的需求自定义每个新闻源的条目数量，以及整体输出的格式和风格。
- **Markdown 格式输出**：以 Markdown 格式输出新闻标题、摘要、发布时间和链接，方便用户在文档中进行引用和编辑。
- **实时更新**：News Feed 实时监控新闻源，确保用户能够获取到最新的新闻资讯。

## 使用指南

### 安装

确保您的系统已安装 Python 3.x 版本。您可以通过以下命令安装 News Feed：

```bash
pip install news-feed
```

### 命令行使用

News Feed 提供以下命令行命令：

#### 获取所有新闻标题

```bash
python3 news.py
```

#### 获取特定来源的新闻标题

```bash
python3 news.py --source bbc
python3 news.py --source reuters
python3 news.py --source ap
python3 news.py --source aljazeera
python3 news.py --source npr
python3 news.py --source guardian
python3 news.py --source dw
```

#### 获取特定主题的新闻标题

```bash
python3 news.py --topic "climate"
python3 news.py --source bbc --topic "ukraine"
```

#### 控制每个源的新闻条目数量

```bash
python3 news.py --limit 20
```

#### 列出所有可用来源

```bash
python3 news.py --list-sources
```

## 输出格式

News Feed 以 Markdown 格式输出新闻标题、摘要、发布时间和链接，格式如下：

```markdown
## BBC
- [标题](链接) - 摘要 - 发布时间
- [标题](链接) - 摘要 - 发布时间
- ...
## Reuters
- [标题](链接) - 摘要 - 发布时间
- [标题](链接) - 摘要 - 发布时间
- ...
```
