# Sonos 控制工具 - 专业版

## 概述

Sonos控制工具-专业版是一款强大的企业级音频控制平台，它基于免费版的功能，进一步扩展了多区域编排、语音助手集成、场景自动化、设备健康监控和API接口等功能，旨在为商业空间和智能建筑提供全面高效的音频解决方案。

## 核心功能

### 1. 多区域编排

- **功能描述**：能够将多个区域编排为场景，一键切换不同区域的播放状态与音源。
- **输入参数**：区域名称、设备列表、音量等。
- **输出结果**：操作结果，包括成功与否、状态码、设备响应等信息。

### 2. 语音助手集成

- **功能描述**：集成Alexa/Google Assistant，通过语音控制Sonos设备。
- **输入参数**：语音指令内容。
- **输出结果**：操作结果，包括成功与否、状态码、设备响应等信息。

### 3. 场景自动化

- **功能描述**：基于时间、事件或传感器触发自动切换音频场景。
- **输入参数**：场景名称、触发条件、操作指令等。
- **输出结果**：操作结果，包括成功与否、状态码、设备响应等信息。

### 4. 商业背景音乐

- **功能描述**：支持商业背景音乐播放列表管理、定时轮播、广告插播。
- **输入参数**：播放列表、定时轮播、广告插播等。
- **输出结果**：操作结果，包括成功与否、状态码、设备响应等信息。

### 5. 设备健康监控

- **功能描述**：监控所有Sonos设备的在线状态、音量、温度，异常告警。
- **输入参数**：监控项（在线状态、音量、温度等）、阈值、告警通知等。
- **输出结果**：监控结果，包括设备状态、异常情况、告警信息等。

### 6. API接口

- **功能描述**：提供RESTful API，支持与智能家居系统、BMS集成。
- **输入参数**：API请求类型、请求参数等。
- **输出结果**：API响应，包括成功与否、状态码、数据内容等。

### 7. 多用户权限

- **功能描述**：按区域分配控制权限，不同员工只能控制授权区域。
- **输入参数**：用户角色、区域权限等。
- **输出结果**：操作结果，包括成功与否、状态码、用户权限信息等。

## 使用场景

### 场景一：餐厅多区域音频管理

- **功能应用**：通过自然语言指令触发，自动执行相应操作并返回结构化结果。
- **示例**：用户可以通过语音指令“设置大厅音量为30”来调整大厅的音量。

### 场景二：定时场景自动化

- **功能应用**：按营业时间自动切换音频场景。
- **示例**：在早晨8:50自动切换到“早餐”场景，并设置音量为30。

### 场景三：广告插播

- **功能应用**：在背景音乐中定时插播广告。
- **示例**：每隔30分钟插播30秒的广告。

### 场景四：设备健康监控

- **功能应用**：监控所有Sonos设备的在线状态、音量、温度，异常告警。
- **示例**：当设备温度过高时，自动发送告警通知。

### 初始化商业场所

```bash
# 创建场所
./sonos-pro venue create \
  --name "阳光餐厅" \
  --address "XX路XX号" \
  --admin "manager@restaurant.com"
# ...
# 扫描并分配设备
./sonos-pro device scan --venue "阳光餐厅"
./sonos-pro device assign --venue "阳光餐厅" --zone "大厅" --devices "speaker-01,speaker-02"
```

**响应解析**：完成操作后，查看输出响应确认任务状态。成功时输出包含解析摘要和响应数据；失败时根据错误信息排查问题，查阅错误解析章节获取恢复步骤。

## 常见问题

### Q: 商业空间需要多少 Sonos 设备?

A: 取决于空间大小与布局。一般每 20-30 平方米一个音箱。餐厅大厅可能需要 4-8 个，包间各 1 个。建议请专业声学设计师评估，确保音质均匀覆盖。

### Q: 广告插播会中断音乐吗?

A: 专业版支持平滑插播：暂停当前音乐 -> 播放广告 -> 恢复音乐（从暂停位置继续）。用户感知为短暂的广告间隔，不会丢失音乐进度。

### Q: 如何与楼宇管理系统(BMS)集成?

A: 专业版提供 RESTful API，BMS 通过 HTTP 调用控制 Sonos。例如消防系统触发时，BMS 调用 API 停止所有音乐并播放紧急广播。API 支持 OAuth2 认证，确保安全。

### Q: 多场所如何统一管理?

A: 专业版支持多场所管理，在一个控制台中管理多个餐厅/门店的音频系统。每个场所独立配置场景与自动化，总部可统一推送播放列表与广告。

- 告警通知:配置 `SMTP_HOST` 和 `ALERT_PHONE`

## 边界条件与限制

### 输入限制

- **输入数据格式**：输入数据必须符合规定的JSON格式，否则技能将无法正确解析和处理。
- **字符长度**：输入字符串长度不应超过1024个字符，以避免性能问题和潜在的内存溢出。
- **参数类型**：所有输入参数的类型必须与API预期一致，否则可能导致错误。

### 性能边界

- **并发处理**：技能支持一定数量的并发请求，但超过限制可能导致服务不可用。
- **处理时间**：对于复杂的操作，如场景自动化和设备健康监控，处理时间可能较长，请耐心等待。

### 兼容性约束

- **操作系统**：目前仅支持Windows、macOS和Linux操作系统。
- **网络环境**：需要与Sonos设备在同一局域网内，或通过VPN连接。
- **Node.js版本**：需要Node.js 18+版本，以确保API服务的正常运行。

### 设备限制

- **设备数量**：技能支持管理大量Sonos设备，但具体数量取决于设备的性能和网络条件。
- **设备类型**：仅支持Sonos品牌的音频设备。

### API Key限制

- **API Key有效期**：API Key有效期为一年，到期后需要重新申请。
- **API Key权限**：API Key的权限限制决定了技能可以执行的操作范围。

- **语音助手支持**：目前仅支持Alexa和Google Assistant语音助手。
