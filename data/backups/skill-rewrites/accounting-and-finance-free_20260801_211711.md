## 能力清单
### 一、基础财务比率分析

### 偿债能力分析
- **流动比率**: 流动资产 / 流动负债,衡量短期偿债能力
  输入: 资产负债表(流动资产、流动负债) → 输出: 流动比率值 + 经验阈值对比(经验值2.0为健康)
- **速动比率**: (流动资产 - 存货) / 流动负债,剔除存货后的短期偿债能力
  输入: 资产负债表(流动资产、存货、流动负债) → 输出: 速动比率值 + 阈值对比(经验值1.0为健康)
- **资产负债率**: 总负债 / 总资产,衡量长期偿债能力与财务杠杆
  输入: 资产负债表(总负债、总资产) → 输出: 资产负债率 + 行业参考区间

### 盈利能力分析
- **毛利率**: (营业收入 - 营业成本) / 营业收入,衡量产品基础盈利能力
  输入: 利润表(营业收入、营业成本) → 输出: 毛利率 + 行业对比
- **净利率**: 净利润 / 营业收入,衡量整体盈利能力
  输入: 利润表(净利润、营业收入) → 输出: 净利率 + 同比变化
- **ROE(净资产收益率)**: 净利润 / 平均股东权益,衡量股东资本回报水平
  输入: 利润表(净利润) + 资产负债表(期初/期末股东权益) → 输出: ROE + 杜邦分解

### 二、DuPont杜邦分析(三因素)
- **ROE分解**: ROE = 净利润率 × 总资产周转率 × 权益乘数
  - 净利润率 = 净利润 / 营业收入(盈利能力)
  - 总资产周转率 = 营业收入 / 平均总资产(营运效率)
  - 权益乘数 = 平均总资产 / 平均股东权益(财务杠杆)
  输入: 利润表 + 资产负债表 → 输出: 三因素分解表 + ROE驱动因素定位

### 三、现金流结构分析
- **现金流结构占比**: 经营/投资/筹资三大现金流净额占比,判断现金流健康度
  输入: 现金流量表(经营/投资/筹资净额) → 输出: 结构占比表 + 健康度评估
  - 健康模式: 经营现金流为正且占比高,投资为负(持续投入),筹资视阶段而定
  - 预警模式: 经营现金流持续为负,依赖筹资续命

## 使用方法
### 1. 数据准备
收集目标企业财务报表数据:
1. 资产负债表(期末数,建议取2期用于计算平均值)
2. 利润表(本期数据)
3. 现金流量表(本期数据)
4. 数据来源: 年报、季报、企业内部报表

### 2. 数据校验
5. 检查三大报表基本勾稽关系(资产 = 负债 + 所有者权益)
6. 确认关键科目无缺失(流动资产、流动负债、净利润、营业收入等)
7. 如数据不全,标注缺失项并使用可获取数据进行替代分析

### 3. 比率计算
按分析目标选择对应比率:
8. **偿债能力** → 计算流动比率、速动比率、资产负债率
9. **盈利能力** → 计算毛利率、净利率、ROE
10. **综合诊断** → 执行DuPont三因素分解

### 4. 趋势对比
11. 将计算结果与经验阈值对比(流动比率2.0、速动比率1.0等)
12. 如有多期数据,进行同比/环比趋势分析
13. 与同行业可比公司进行横向对比(需用户提供对标数据)

### 5. 生成结论
输出分析结论,包含: 关键比率表 + 健康度评级 + 主要风险点 + 改善建议

结论: 偿债能力适中,盈利能力良好,现金流结构健康.

## 异常响应
| 错误场景 | 原因分析 | 处理方式 |
|:------:|--------|:-------|
| 财报数据缺失关键科目 | 年报披露不全或科目重分类 | 标注缺失项,使用可获取科目进行分析,无法计算的比率标注"数据不全" |

## 常见问题与故障排查

### Q1: 如何处理财务报表中缺失的科目数据？
A: 当财务报表中缺失关键科目数据时，应首先检查年报披露是否完整或是否存在科目重分类。如果数据不全，可以尝试使用可获取的科目进行分析，并在无法计算的情况下标注'数据不全'。

### Q2: 在进行ROE分析时，如何判断ROE是否合理？
A: ROE没有绝对标准，需要结合行业和资本结构来判断。一般经验是：ROE > 15%为优秀，10%-15%为良好，< 8%为偏低，但需警惕ROE过高（>30%），可能是高杠杆驱动，需结合DuPont分解判断。

### Q3: 权益乘数在DuPont分析中是什么意思？
A: 权益乘数等于总资产除以股东权益，反映财务杠杆。高权益乘数意味着负债占比高，一方面能放大ROE（杠杆效应），另一方面增加财务风险（偿债压力、利息负担）。判断时需结合资产负债率和行业惯例。

### Q4: 为什么免费版不支持估值分析？
A: 免费版仅提供基础财务比率、DuPont和现金流结构分析，不支持DCF/DDM/CCA等估值建模。如需估值定价，请升级至accounting-and-finance付费版。

### Q5: 经营现金流为负是否一定是坏事？
A: 不一定，需结合企业阶段判断。成长期企业可能因应收账款和存货占用导致经营现金流暂时为负，而成熟期企业持续为负可能存在盈利质量问题。

## 代码示例

### 示例1: 计算流动比率
```python
# 假设资产负债表数据如下
assets = {'current_assets': 12500, 'inventory': 4200, 'total_assets': 28000, 'current_liabilities': 6800, 'total_liabilities': 13500, 'equity': 14500}
liquidity_ratio = assets['current_assets'] / assets['current_liabilities']
print(f'流动比率: {liquidity_ratio:.2f}')
```

### 示例2: DuPont分析计算
```python
# 假设利润表和资产负债表数据如下
net_profit = 1620
revenue = 18000
average_total_assets = (assets['total_assets'] + assets['total_assets']) / 2
average_equity = (assets['equity'] + assets['equity']) / 2

# 计算净利润率
net_profit_margin = net_profit / revenue

# 计算总资产周转率
total_asset_turnover = revenue / average_total_assets

# 计算权益乘数
equity_multiplier = average_total_assets / average_equity

# 计算ROE
roe = net_profit_margin * total_asset_turnover * equity_multiplier
print(f'DuPont分析结果: ROE = {roe:.2f}')
```

## FAQ章节

### Q1: 如何理解财务比率分析中的“经验阈值”？
A: 经验阈值是指根据历史数据和行业经验总结出的财务指标合理范围。例如，流动比率的经验阈值通常在2.0以上，表示企业的短期偿债能力较好。使用经验阈值可以帮助快速评估企业的财务健康状况。

### Q2: 在进行杜邦分析时，如何解释权益乘数的变化？
A: 权益乘数的变化反映了企业财务杠杆的使用情况。如果权益乘数增加，意味着企业使用了更多的债务融资，这可能提高了ROE，但也增加了财务风险。相反，如果权益乘数下降，可能表示企业减少了债务融资，降低了财务风险。

### Q3: 如何处理财务报表中存货数据的缺失？
A: 如果存货数据缺失，可以尝试使用其他相关数据（如总资产、总负债）进行间接计算。例如，可以通过总资产减去流动资产（不含存货）来估算存货。

### Q4: 在进行现金流结构分析时，如何判断现金流健康度？
A: 现金流健康度可以通过分析经营活动、投资活动和筹资活动的现金流净额占比来判断。如果经营活动现金流为正且占比高，表明企业有稳定的现金流来源；如果投资活动为负且合理，表示企业处于扩张阶段；筹资活动视企业阶段而定。

### Q5: 如何确保财务分析结果的准确性？
A: 确保财务分析结果准确性的关键在于：
1. 使用经审计的财务报表数据。
2. 确保数据的一致性和准确性。
3. 使用正确的财务指标和计算方法。
4. 定期更新分析结果，以反映最新的财务状况。
