## 功能

每晚 22:00 自动扫描明天的 Outlook 日历，按时间段设置提醒：

* 上午日程（< 12:00）→ 提前 2 小时飞书提醒
* 下午日程（>= 12:00）→ 当天 12:00 统一飞书提醒
* 扫描完成后立即发送汇报消息

## 依赖

* `owa-outlook` skill（提供 `owa_calendar.py`）
* `skill-platform` CLI
* Python 3.9+（需要 `zoneinfo` 模块）

## 依赖说明

### 1. 注册每晚扫描 cron

```bash
skill-platform cron add \
  --name "calendar-daily-scan" \
  --cron "0 22 * * *" \
  --tz "Asia/Shanghai" \
  --session main \
  --system-event "CALENDAR_SCAN: 请立即运行 python3 ~/.skill-platform/workspace/skills/calendar-reminder/calendar_reminder.py 并等待完成" \
  --description "每晚22:00扫描明天日历并设置提醒"
```

## 常见问题

### Q1: 如何设置Calendar Reminder Skill的提醒事项？
A: 您可以通过以下步骤设置提醒事项：
1. 打开Calendar Reminder Skill。
2. 选择“新建提醒”或点击“+”按钮。
3. 输入提醒事项的标题。
4. 选择提醒的时间，可以是具体时间或重复提醒。
5. 设置提醒的重复周期（如每天、每周、每月等）。
6. 点击“保存”完成设置。

### Q2: Calendar Reminder Skill支持哪些类型的提醒？
A: Calendar Reminder Skill支持以下类型的提醒：
- 一次性提醒
- 每日提醒
- 每周提醒
- 每月提醒
- 定时提醒

### Q3: 如何修改已设置的提醒事项？
A: 修改已设置的提醒事项，请按照以下步骤操作：
2. 进入“我的提醒”或“提醒列表”。
3. 找到您想要修改的提醒事项。
4. 点击该提醒事项，进入编辑页面。
5. 修改标题、时间、重复周期等设置。
6. 点击“保存”以保存更改。

### Q4: Calendar Reminder Skill的提醒会在哪些设备上显示？
A: Calendar Reminder Skill的提醒会在您所有已连接的设备上显示，包括手机、平板电脑和电脑等。

### Q5: 如果我错过了提醒，如何再次设置提醒？
A: 如果您错过了提醒，可以按照以下步骤重新设置：
2. 进入“我的提醒”或“提醒列表”。
3. 找到已过期的提醒事项。
4. 点击该提醒事项，进入编辑页面。
5. 修改提醒的时间，确保下次不会错过。
6. 点击“保存”以保存更改。
