## Figma Studio Free 技能文档

### 概述

Figma Studio Free 是一款基于 Figma REST API 开发的自动化工具，旨在简化 Figma 文件的处理流程，包括读取、导出、设计令牌提取等操作。本文档旨在为用户提供全面、详细的技术指南，确保用户能够高效、安全地使用 Figma Studio Free。

### 故障排查 (Troubleshooting)

#### 问题1：读取 Figma 文件时出现“授权失败”错误
**原因分析**：Token 过期或配置错误可能是导致“授权失败”错误的主要原因。
**解决方案**：
1. 检查 OAuth2 配置，确保客户端 ID 和客户端密钥正确。
2. 重新获取 Token，确保其有效性。

#### 问题2：导出图片时图片质量不理想
**原因分析**：导出参数设置不正确或图片分辨率过低可能导致图片质量不理想。
**解决方案**：
1. 调整导出参数，选择合适的分辨率和格式。
2. 确保导出格式为支持的图片格式，如 PNG、JPEG 等。

#### 问题3：设计令牌提取失败
**原因分析**：设计文件中未正确配置设计令牌可能导致提取失败。
**解决方案**：
1. 检查设计文件，确保设计令牌已正确添加到组件中。

#### 问题4：API 调用超时
**原因分析**：网络连接不稳定或 Figma API 服务器响应缓慢可能导致 API 调用超时。
**解决方案**：
1. 检查网络连接，确保稳定。
2. 尝试重试 API 调用。
3. 联系 Figma 支持寻求帮助。

#### 问题5：无法获取文件列表
**原因分析**：用户权限不足或 API 密钥权限受限可能导致无法获取文件列表。
**解决方案**：
1. 确保用户有足够的权限访问文件。
2. 检查 API 密钥权限设置。

### 边界条件与限制 (Boundary Conditions)

#### 输入限制
- 文件读取功能限制于单个文件，不支持批量读取。
- 图片导出功能限制于单个文件，不支持批量导出。

#### 性能边界
- 单次 API 调用处理的数据量有限，超过限制可能导致性能问题。
- 设计令牌提取和 CSS 变量转换模板的性能受限于设计文件的大小和复杂性。

#### 兼容性约束
- 该技能仅支持 Figma REST API，不支持 Figma Web API。
- 部分功能可能受限于 Figma API 的版本更新。

### 安全注意事项 (Security Notes)

#### API 密钥处理
- 确保 API 密钥安全存储，避免泄露给未授权人员。
- 定期更换 API 密钥，以降低安全风险。

#### 数据安全
- 在处理敏感数据时，确保遵循相关数据保护法规。
- 对传输数据进行加密，以防止数据泄露。

#### 权限要求
- 确保用户拥有足够的权限访问所需资源，如文件、组件和样式。
- 限制 API 密钥的权限，避免未授权操作。
