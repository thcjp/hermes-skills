# 插件架构工具 - 免费版
## 能力总览
### 1. 视图注册
插件可通过 `registerView` API 注册自定义视图,视图会出现在控制台的侧边栏导航中.
**处理**: 解析视图注册的输入参数,完成核心逻辑,返回处理结果.
**输出**: 返回视图注册的响应数据,包含状态信息、结果数据和执行记录.
### 2. 导航分组
支持将视图分配到不同的导航分组(如 Chat、Control、Agent、Settings),与内置功能有机融合.
**处理**: 解析导航分组的输入参数,完成核心逻辑,返回处理结果.
**输出**: 返回导航分组的响应数据,包含状态信息、结果数据和执行记录.
- 通过`input_params`参数指定操作类型(创建/查询/导出)
### 3. 图标与排序
每个视图可配置图标、标签和排序位置,灵活控制界面布局.
**处理**: 解析图标与排序的输入参数,完成核心逻辑,返回处理结果.
**输出**: 返回图标与排序的响应数据,包含状态信息、结果数据和执行记录.
- 通过`input_params`参数指定操作类型(创建/查询/导出)
### 依赖详情
提供详细的安装说明与参考代码,Agent 可按步骤完成安装.
**处理**: 解析依赖说明的输入参数,完成核心逻辑,返回处理结果.
**输出**: 返回依赖说明的响应数据,包含状态信息、结果数据和执行记录.
- 通过`input_params`参数指定操作类型(创建/查询/导出)

## 优选实践指南
1. **ID 唯一性**:视图 ID 使用插件名前缀(如 `myplugin-panel`),避免与其他插件冲突
2. **合理排序**:position 值间隔 5 或 10,便于后续插入新视图
3. **选择合适分组**:按功能选择正确的导航分组,不要全部放在 Control
4. **简洁的标签**:label 控制在 4 个字以内,subtitle 用于补充说明
5. **防御性编程**:注册前检查 `api.registerView` 是否存在,确保向后兼容

### 性能边界
- **并发处理**：插件架构工具免费版不支持高并发场景下的视图注册和导航操作。在高并发情况下，可能需要等待其他操作完成。

### 兼容性约束
- **Agent平台**：该技能仅在支持SKILL.md的AI Agent平台上可用，如Claude Code、Cursor、Codex、Gemini CLI等。
- **操作系统**：该技能在Windows、macOS和Linux操作系统上运行，但具体兼容性取决于Agent平台。
- **开发环境**：需要Node.js 16+和TypeScript环境，以及React UI框架。不同版本的Node.js和TypeScript可能需要不同的适配。
### 其他限制
- **免费版功能限制**：免费版仅提供基础视图注册和导航功能，不支持动态添加/移除视图、插件市场、权限管控和热更新等高级功能。

## 故障恢复流程

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
