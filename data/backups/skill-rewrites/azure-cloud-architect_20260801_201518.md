# Azure云架构师

使用本地Azure CLI回答关于Azure资源的问题。默认只读查询,仅在用户明确要求变更并确认后执行写/破坏性操作.
## 核心能力

### 1. 多订阅导航器
自动列出所有可访问订阅,智能检测默认订阅,支持按名称或ID切换,避免在错误订阅执行操作

**处理**: 解析多订阅导航器的输入参数,完成核心逻辑,输出标准化响应数据.
**输出**: 返回多订阅导航器的响应数据,含执行状态与操作日志.
- 通过`input_params`参数指定操作类型(创建/查询/导出)
### 2. 分层权限模型
L0只读直接执行、L1预演展示计划、L2确认写、L3破坏性详细影响分析、L4敏感操作双重确认,保障生产环境安全

**处理**: 解析分层权限模型的输入参数,完成核心逻辑,输出标准化响应数据.
**输出**: 返回分层权限模型的响应数据,含执行状态与操作日志.
- 通过`input_params`参数指定操作类型(创建/查询/导出)
### 3. 安全审计剧本
RBAC角色审计(检测Owner过度授权)、存储安全检查(公共访问/HTTPS/TLS)、NSG规则检查(0.0.0.0/0入站)、Key Vault访问审计

**处理**: 解析安全审计剧本的输入参数,完成核心逻辑,输出标准化响应数据.
**输出**: 返回安全审计剧本的响应数据,含执行状态与操作日志.
- 通过`input_params`参数指定操作类型(创建/查询/导出)
### 4. 成本分析工作流
按资源组/服务维度查询Cost Management,识别空闲资源(停止的VM/未挂载磁盘/未使用公网IP)以优化成本

**处理**: 解析成本分析工作流的输入参数,完成核心逻辑,输出标准化响应数据.
**输出**: 返回成本分析工作流的响应数据,含执行状态与操作日志.
- 通过`input_params`参数指定操作类型(创建/查询/导出)
### 5. 跨订阅批量操作
提供跨订阅遍历模板,统一执行VM列举、NSG检查等操作,避免遗漏订阅

**处理**: 解析跨订阅批量操作的输入参数,完成核心逻辑,输出标准化响应数据.
**输出**: 返回跨订阅批量操作的响应数据,含执行状态与操作日志.
**技术参数**：使用`input_params`和`output_format`参数控制执行行为,支持`json`/`text`/`csv`输出格式.
**能力覆盖范围**：能力范围包括以下关键词：角色审计最小权限、合规检查、Azure、CLI、的智能云基础设施、管理助手、角色审计与最小权、合规检查清单、跨订阅批量操作五、大核心能力、适用于、资源盘点、健康监控、多订阅多租户管理、默认只读查询、写操作与破坏性操、作需确认、适用关键词、云架构师、基础设施管理、cloud、architect等。这些关键词对应description中声明的使用场景,均已在上述能力点中提供对应的操作支持.

**输入**: "审计一下当前订阅里谁有Owner角色,检查是否有过度授权"

**输出**:
```bash
az role assignment list --role "Owner" --query '[].{Assignee:principalName,Scope:scope}' --output table

### 示例3: 跨订阅成本分析
**输入**: "查询本月各资源组的成本"

**输出**:
```bash
az costmanagement query --type ActualCost \
  --timeframe MonthToDate \
  --dataset-grouping name=ResourceGroupName type=Dimension \
  --dataset-aggregation totalCost=name=Cost function=Sum
```
返回各资源组的本月累计成本数据.

| 服务故障 | 500-503 | 服务器内部错误 | 等待恢复后重试,最多2次 |

## 已知限制

1. **仅支持Azure CLI命令**:不提供Azure Portal GUI操作指导,不覆盖Azure SDK编程开发场景
2. **依赖本地Azure CLI环境**:需提前安装并配置Azure CLI,未安装时无法使用
3. **成本查询依赖订阅类型**:CSP等部分订阅类型可能不支持Cost Management,返回空结果
4. **跨订阅操作性能受限**:遍历多订阅时为串行执行,订阅数量多时耗时较长
5. **不修改Azure资源默认行为**:所有写操作需用户显式确认,自动化流水线场景需额外集成确认机制

## 边界条件与限制

### 输入限制
- **订阅数量限制**：技能不支持超过特定数量的订阅，因为大量订阅的遍历可能会导致性能问题。
- **资源类型限制**：技能可能不支持所有Azure资源类型，特别是那些不通过Azure CLI直接管理的资源。
- **命令复杂性限制**：技能可能无法处理过于复杂的Azure CLI命令，特别是那些需要嵌套或大量参数的命令。

### 性能边界
- **命令执行时间**：对于某些操作，如跨订阅批量操作，由于串行执行，可能会受到性能限制，特别是在订阅数量较多的情况下。
- **资源查询深度**：技能可能无法处理深层嵌套的资源查询，因为Azure CLI命令的输出格式可能不支持深度解析。

### 兼容性约束
- **Azure CLI版本**：技能依赖于特定版本的Azure CLI，如果用户使用的是旧版本，可能需要升级。
- **操作系统兼容性**：技能在Windows、macOS和Linux操作系统上运行，但不保证在所有版本的操作系统上都能正常工作。
- **网络连接**：技能需要稳定的网络连接来执行Azure CLI命令，网络问题可能导致操作失败。

### 安全和合规性
- **敏感数据输出**：技能不会在输出中包含敏感数据，如密钥或令牌，但用户需要确保在处理输出时保护这些信息。
- **最小权限原则**：技能遵循最小权限原则，用户需要确保其Azure CLI身份具有执行所需操作的最小权限。

## 差异化优势

### 与同类方案对比

在Azure云架构师领域，存在一些替代方案，如手动操作、Azure Portal GUI、以及一些第三方管理工具。以下是与这些方案的对比：

1. **手动操作**：手动操作通常需要通过Azure Portal GUI或Azure CLI逐个订阅和资源进行管理。这种方式效率低下，容易出错，且难以进行跨订阅的批量操作。相比之下，本技能提供自动化的多订阅导航和跨订阅批量操作功能，大幅提高了操作效率，减少了人为错误。

2. **Azure Portal GUI**：Azure Portal GUI提供了直观的用户界面，但操作流程繁琐，且缺乏自动化和脚本化能力。本技能通过Azure CLI提供自动化操作，减少了操作步骤，并支持脚本化，使得复杂任务可以自动化执行。

3. **第三方管理工具**：一些第三方工具提供了丰富的功能，但可能需要额外的部署和维护成本。本技能作为开源工具，无需额外成本，且易于集成到现有的工作流程中。

### 独特功能

1. **多订阅导航器**：自动列出所有可访问订阅，并支持按名称或ID切换，极大地简化了多订阅环境下的资源管理。

2. **分层权限模型**：提供从只读查询到破坏性操作的分层权限控制，确保生产环境的安全。

3. **安全审计剧本**：内置RBAC角色审计、存储安全检查、NSG规则检查等功能，帮助用户及时发现和修复安全漏洞。

4. **成本分析工作流**：自动识别空闲资源，提供成本优化的建议，帮助用户降低云成本。

5. **跨订阅批量操作**：支持跨订阅遍历模板，统一执行VM列举、NSG检查等操作，避免了因遗漏订阅而造成的问题。
