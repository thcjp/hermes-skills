# 并行研究助手（免费版）

## 概述

并行研究助手免费版是一款帮助用户围绕特定主题开展开放式研究的工具。核心理念是"对话是短暂的，文档才是重要的"。为每个研究主题创建独立的研究文件夹，通过交互式对话逐步搜索、综合和更新研究文档，最终形成结构化的知识沉淀.
本版本聚焦交互式研究模式，适合个人开发者技术方案调研、学生课题研究和独立创业者市场验证。如需深度异步研究、批量并行处理和 API 集成等高级能力，可升级至 PRO 版本.

## 常见问题

### Q1：研究文档保存在哪里？

研究文档保存在 `./.research-workspace/research/<topic-slug>/` 目录下，每个研究主题独立文件夹.
### Q2：免费版支持深度异步研究吗？

免费版不支持深度异步研究模式（需要 parallel-research CLI）。免费版仅支持交互式研究模式，即用户与 Agent 实时对话推进研究.
### Q3：可以同时进行多个研究吗？

免费版建议单主题研究。如需多主题并行研究，请升级至 PRO 版本.
### Q4：PDF 导出需要什么工具？

PDF 导出需要安装 pandoc 和 PyMuPDF。可通过系统包管理器安装.
```bash
# 在此执行相关操作
echo "操作完成"
```

### Q5：免费版与 PRO 版本的区别？

| 对比项 | 免费版 | PRO 版本 |
|---:|---:|---:|
| 研究模式 | 交互式 | 交互式+深度异步 |
| 并发主题 | 1个 | 10+个并行 |
| 处理器等级 | 不适用 | lite-ultra8x可选 |
| API 集成 | 不支持 | REST API |
| 团队协作 | 不支持 | 多租户 |
| 定时研究 | 不支持 | cron调度 |
| 导出格式 | PDF | PDF/Word/HTML |
| 历史管理 | 基础 | 版本管理 |

## 边界条件与限制 (Boundary Conditions)

并行研究助手免费版在设计时考虑了多种边界条件和限制，以确保工具的稳定性和实用性。以下是一些关键的边界条件和限制：

- **单主题研究限制**：免费版仅支持单个主题的研究，即在同一时间只能处理一个研究项目。这限制了用户无法同时进行多个并行研究。
- **交互式研究模式**：免费版仅提供交互式研究模式，用户需要与Agent实时互动来推进研究过程。不支持深度异步研究，即用户不能设置研究任务自动执行。
- **资源访问限制**：免费版可能对某些高级资源的访问有限制，例如某些数据库或API的访问可能需要额外付费。
- **文档处理能力**：对于大型或复杂的文档，免费版可能无法提供与PRO版本相同级别的处理能力，这可能会影响研究的效率和深度。
- **存储空间限制**：免费版可能对每个研究主题的文档大小或存储空间有上限，超出限制可能会导致文件无法保存。
- **功能限制**：免费版不支持API集成、团队协作、定时研究和多租户等功能，这些功能仅在PRO版本中提供。
- **性能限制**：由于免费版的性能限制，处理大型或复杂的研究项目可能需要更长时间，并且可能会影响响应速度。
- **兼容性限制**：某些第三方工具或服务可能需要额外配置或安装，而这些配置或安装可能不在免费版的支持范围内。

这些边界条件和限制确保了并行研究助手免费版在提供基本研究功能的同时，不会过度承诺或提供超出其能力范围的服务。
