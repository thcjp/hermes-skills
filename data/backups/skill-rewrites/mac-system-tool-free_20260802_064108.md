## 导读
本工具帮助个人用户管理与控制 macOS 系统功能：系统信息、进程、磁盘、电池查询，音量亮度网络控制，截图剪贴板 Finder 操作。破坏性操作（关机、重启、杀进程）二次确认.

```bash
# CPU 占用前 10
ps aux --sort=-%cpu | head -11
# ...
# 内存占用前 10
ps aux --sort=-%mem | head -11
# ...
# 查找进程
pgrep -fl "chrome"
# ...
# 结束进程（先确认）
kill PID          # 正常结束
kill -9 PID       # 强制结束（谨慎）
```

### 网络诊断

```bash
# WiFi 信息

# ...

# ...

traceroute example.com
```

## 能力边界说明
Mac 系统工具（免费版）在设计和实现时考虑了以下边界条件和限制：

### 输入限制

- **参数格式**：输入参数必须符合预定义的格式，否则工具将无法正确解析和执行。
- **数据类型**：输入数据类型必须与预期类型匹配，例如，音量设置应为数值类型。
- **长度限制**：某些参数如命令行输入可能存在长度限制，超出限制可能导致错误。

### 性能边界

- **并发处理**：工具设计为单线程执行，高并发场景下可能存在性能瓶颈。
- **资源消耗**：某些操作如截图和进程管理可能对系统资源有较高消耗，长时间运行可能导致系统响应变慢。

### 兼容性约束

- **操作系统版本**：工具主要针对 macOS 系统，Windows/Linux 系统可能存在部分命令不兼容的情况。
- **软件依赖**：部分功能依赖于系统工具或第三方软件，如 `brightness` 工具需要通过 Homebrew 安装。

### 破坏性操作

- **二次确认**：对于关机、重启、杀进程等破坏性操作，工具会进行二次确认，以避免误操作。
- **不可逆操作**：某些操作如关机重启是不可逆的，执行前务必确认。

### 安全性

- **权限要求**：部分操作如清空废纸篓需要管理员权限，执行前会提示用户输入密码。
- **敏感信息**：工具不存储任何敏感信息，如剪贴板内容在操作完成后会被清除。

### 其他限制

- **定时任务**：免费版不支持定时任务和自动化策略，这些功能为专业版独有。
- **多设备管理**：工具不支持多台 Mac 的远程管理，仅限于单台设备操作。
