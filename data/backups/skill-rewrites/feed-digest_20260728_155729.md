# Feed Digest

Streamline your content consumption with Feed Digest, an advanced tool designed to help you manage your subscriptions efficiently and keep track of your reading status.

## Overview

Feed Digest is an essential tool for anyone dealing with information overload. It allows you to aggregate content from various sources and manage your reading experience effectively.

## Workflow

Follow this structured workflow to make the most out of Feed Digest:

1. **Fetch New Content** — Use `feed fetch` to pull in the latest entries from your subscribed feeds.
2. **Scan Recent Entries** — Execute `feed get entries --limit N` to review recent unread entries (including title, feed, date, and summary).
3. **Triage Content** — Select 5-10 high-priority posts based on relevance and interest, prioritizing topics such as AI advancements, systems engineering, and developer tools.
4. **Read Selected Articles** — Retrieve the full post in Markdown format using `feed get entry <id>`.
5. **Synthesize and Organize** — Summarize each article in 2-3 sentences and group them by theme if relevant.
6. **Mark as Read** — Use `feed update entries --read <id1> <id2> ...` to update your read status for the selected entries.

## Commands Reference

```text
feed fetch                              # Pull the latest content from all feeds
feed get entries --limit N              # List unread entries (in table format)
feed get entries --feed <id> --limit N  # Filter entries by feed
feed get entry <id>                     # Read the full post (in Markdown)
feed search "<query>"                   # Perform a full-text search
feed update entries --read <id> ...     # Mark entries as read
feed get feeds                          # List all feeds with unread counts
feed get stats                          # Retrieve database statistics
```

## Notes

- **Output Format**: The default output is in table format, which is most efficient for quick scanning. Avoid using `-o json` unless necessary.
- **Markdown Format**: The content of each article is returned in Markdown format for easy reading and editing.
- **Filtering by Feed**: Use `--feed <feed_id>` to filter entries by a specific feed if needed.
