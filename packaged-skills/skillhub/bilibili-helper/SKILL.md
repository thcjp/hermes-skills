# Bilibili Helper

B站视频运营助手。标题、简介、标签、分区建议、评论互动。

## Usage

```bash
bili.sh title "主题"

bili.sh desc "视频主题"

bili.sh script "主题" [--length 5|10|15]

bili.sh tags "主题"

bili.sh help
```

## When to Use

* 用户要发B站视频，需要标题/简介/标签
* 需要写视频口播脚本
* 需要B站运营建议和内容策划

脚本使用 Python 生成符合B站平台调性的内容模板，包含标题公式、简介结构、标签策略等。

## Commands

| Command | Description |
| --- | --- |
| `title` | 生成5个B站爆款标题 |
| `desc` | 生成视频简介+标签 |
| `script` | 生成视频口播脚本 |
| `tags` | 标签推荐 |
| `help` | 显示帮助信息 |

## 详细的错误处理说明

为了提高错误处理的准确性，以下列出了Bilibili Helper可能遇到的一些错误场景及其处理方法。

### 错误码定义
- **E001**: 配置错误，参数缺失或格式错误。
- **E002**: 运行时错误，运行环境不满足要求。
- **E003**: 网络错误，连接超时或不可达。
- **E004**: 权限不足，无法访问所需资源。
- **E005**: 依赖库缺失，无法执行功能。

### 错误处理方案
- **E001**: 检查依赖说明中的配置要求，确保所有参数已正确设置。
- **E002**: 确认运行环境符合依赖说明，检查操作系统版本、软件依赖等。
- **E003**: 检查网络连接，确保网络稳定，必要时尝试更换网络环境。
- **E004**: 确保当前用户有足够的权限执行操作，或联系管理员获取权限。
- **E005**: 安装缺失的依赖库，确保所有依赖都已正确安装。

## 边界条件处理

为了确保Bilibili Helper在各种边界条件下的稳定运行，以下列出了一些关键边界条件及其处理方法。

### 边界条件处理
- **空输入**: 当输入为空时，Bilibili Helper将返回一个默认的标题、简介或标签模板。
- **异常字符**: 对于包含异常字符的输入，Bilibili Helper将自动替换或删除这些字符，以避免潜在的运行时错误。
- **过长的输入**: 对于过长的输入，Bilibili Helper将截断输入并提示用户输入过长。
- **不支持的命令**: 当用户输入不支持的命令时，Bilibili Helper将返回错误信息并提示用户正确的命令。
