## 快速上手指南

### 环境要求
- Python版本：Python 3.6+
- 依赖安装命令：`pip install realtime-quote-free`

### 5步操作指南
1. **初始化**：`from realtime_quote_free import RealtimeQuoteFree`
2. **配置**：`quote_free = RealtimeQuoteFree(api_key='YOUR_API_KEY')`
3. **启动**：`quote_free.start()`
4. **获取行情**：`quote_free.get_quote('000001.SZ')`
5. **停止**：`quote_free.stop()`

### 配置示例
```python
quote_free = RealtimeQuoteFree(api_key='YOUR_API_KEY', format='json', options={'output_style': 'compact'})
```
