## 技术验证与权威参考

### 核心公式数学验证

```markdown
F-score = (Current Ratio + Retained Earnings / Total Assets) / 2
```

**数值代入计算**：

假设某公司当前比率（Current Ratio）为2，留存收益与总资产比为0.3，则：

F-score = (2 + 0.3) / 2 = 1.15
