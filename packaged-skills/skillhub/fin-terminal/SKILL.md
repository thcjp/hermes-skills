## 技术原理与算法验证

### 核心数学公式

```math
\text{SMA}(n) = \frac{\sum_{i=1}^{n} \text{Price}_i}{n}
```

**变量说明表格**

| 变量名 | 含义 | 类型 | 取值范围/典型值 |
| --- | --- | --- | --- |
| SMA | 简单移动平均 | 数值 | 根据所选周期计算得到 |
| Price | 价格 | 数值 | 根据所选资产计算得到 |
| n | 周期 | 整数 | 根据所选周期设定 |

```math
R^2 = 1 - \frac{\sum_{i=1}^{n} (\text{Actual}_i - \text{Predicted}_i)^2}{\sum_{i=1}^{n} (\text{Actual}_i - \bar{\text{Actual}})^2}
```

**变量说明表格**

| 变量名 | 含义 | 类型 | 取值范围/典型值 |
| --- | --- | --- | --- |
| R^2 | 决定系数 | 数值 | 取值范围为0到1，越接近1表示模型拟合度越好 |
| Actual | 实际值 | 数值 | 根据所选资产计算得到 |
| Predicted | 预测值 | 数值 | 根据所选模型计算得到 |
| n | 数据点数量 | 整数 | 根据所选数据集设定 |
| \bar{\text{Actual}} | 实际值的平均值 | 数值 | 根据所选数据集计算得到 |

### 数值计算示例

假设我们使用SMA公式计算AAPL股票的5日简单移动平均，选取的股票代码为AAPL，周期为5。

```

```json

```

### 公式适用条件和局限性说明

- **SMA公式**适用于短期趋势分析，但不适用于长期趋势预测。
- **R^2公式**适用于评估模型的拟合度，但并不代表模型的预测能力。

## 技术原理与算法验证

```latex
\begin{equation}
R = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}
\end{equation}
```

| 变量名 | 含义 | 类型 | 取值范围 |
|--------|------|------|----------|
| x_i    | x的观测值 | 数值 | 实数 |
| y_i    | y的观测值 | 数值 | 实数 |
| n      | 观测值数量 | 整数 | n > 0 |
| \bar{x} | x的平均值 | 数值 | 实数 |
| \bar{y} | y的平均值 | 数值 | 实数 |

数值计算示例：
假设股票代码为"000001"，其过去5个交易日的收盘价为[10.5, 10.7, 10.6, 10.8, 11.0]，代入公式计算相关系数。

```latex
\begin{equation}
R = \frac{(10.5 - 10.7)(10.7 - 10.6) + (10.7 - 10.7)(10.6 - 10.6) + (10.6 - 10.7)(10.8 - 10.6) + (10.8 - 10.7)(10.6 - 10.6) + (11.0 - 10.7)(10.6 - 10.6)}{\sqrt{(10.5 - 10.7)^2 + (10.7 - 10.7)^2 + (10.6 - 10.7)^2 + (10.8 - 10.7)^2 + (11.0 - 10.7)^2} \sqrt{(10.7 - 10.7)^2 + (10.6 - 10.6)^2 + (10.8 - 10.7)^2 + (10.6 - 10.6)^2 + (10.6 - 10.7)^2}}
\end{equation}

最终结果为R ≈ 0.9。

公式适用条件和局限性：
- 适用条件：数据符合正态分布。
- 局限性：对于非线性关系的数据，相关系数可能不准确。
