## 技术验证与权威参考

### 核心公式数学验证

**公式**：夏普比率 = (平均收益率 - 无风险收益率) / 标准差

**数值代入计算**：
- 平均收益率 = 10%
- 无风险收益率 = 2%
- 标准差 = 5%

**计算结果**：夏普比率 = (10% - 2%) / 5% = 1.6

## 快速上手指南

### 环境要求
- Python版本：Python 3.6+
- 依赖安装命令：`pip install backtest-engine`

### 5步操作指南
1. 导入backtest引擎：`from backtest_engine import Backtest`
2. 创建Backtest对象：`bt = Backtest(data, strategy, options)`
3. 设置回测参数：`bt.set_parameters(start_date, end_date, frequency)`
4. 执行回测：`result = bt.run()`
5. 输出结果：`print(result)`

### 配置示例
```python
data = {'AAPL': [150, 152, 153, 154, 155]}
strategy = lambda data: data['AAPL'][-1] * 1.01
options = {'start_date': '2020-01-01', 'end_date': '2020-12-31', 'frequency': 'D'}
bt = Backtest(data, strategy, options)
result = bt.run()
print(result)
```
