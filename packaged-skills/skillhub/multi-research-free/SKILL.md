## 技术原理与算法验证

```markdown
# 公式1: MACD计算公式
MACD = (EMA(CLOSE, 12) - EMA(CLOSE, 26)) / EMA(EMA(CLOSE, 12) - EMA(CLOSE, 26), 9)
```

| 变量名 | 含义 | 类型 | 取值范围 |
|--------|------|------|----------|
| CLOSE | 收盘价 | 数值 | [0, +∞) |
| EMA | 指数移动平均 | 数值 | [0, +∞) |

数值计算示例：

```markdown
# 使用股票代码600519
# 假设过去12天和26天的收盘价分别为[10, 11, 12, ..., 25]
# 计算12日和26日EMA
EMA_12 = (10 + 11 + ... + 25) / 12
EMA_26 = (10 + 11 + ... + 25) / 26
# 计算MACD
MACD = (EMA_12 - EMA_26) / EMA(EMA_12 - EMA_26, 9)
```

```markdown
# 公式2: RSI计算公式
RSI = 100 - (100 / (1 + RS))
```

| 变量名 | 含义 | 类型 | 取值范围 |
|--------|------|------|----------|
| RS | 平均收盘价变动率 | 数值 | [0, +∞) |
| R | 收盘价上涨天数 | 数值 | [0, +∞) |
| D | 收盘价下跌天数 | 数值 | [0, +∞) |

数值计算示例：

```markdown
# 使用股票代码000001
# 假设过去14天中，收盘价上涨的天数R为10，下跌的天数D为4
# 计算14天RS
RS = (R / D)
# 计算14天RSI
RSI = 100 - (100 / (1 + RS))
```

公式适用条件和局限性：

- 公式1：适用于股票价格分析，但需要大量历史数据，对市场波动性敏感。
- 公式2：适用于股票价格趋势分析，但可能在高波动市场中失效。
