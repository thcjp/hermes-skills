## 技术原理与算法验证

### 核心数学公式

```plaintext
公式1：Lasso回归（Least Absolute Shrinkage and Selection Operator）
目标函数：min ||Xβ - y||² + λ||β||₁

其中：
  ||Xβ - y||² 为残差平方和（OLS损失项），衡量模型拟合优度
  λ||β||₁   为L1正则化惩罚项，驱动稀疏解（部分β归零）
  λ ∈ (0, +∞) 为正则化强度超参数

公式2：MACD计算
MACD = EMA12 - EMA26
DIF  = MACD - Signal
Signal = 2 * (DIF / (DIF + EMA9))
```

### Lasso回归λ值选择方法（核心参数调优）

λ值是Lasso回归最关键的超参数，直接决定特征筛选的稀疏程度。本技能提供三种λ值选择方法，默认使用交叉验证法：

1. **K折交叉验证法（默认，推荐）**：使用5折交叉验证（5-Fold CV），在λ网格上搜索使验证集MSE最小的λ值。
   - λ网格范围：`np.logspace(-4, 1, 50)`，即 λ ∈ [1e-4, 10]，共50个候选值（对数均匀分布）。
   - 默认选择"1-SE规则"（One-Standard-Error Rule）：在MSE最小值一个标准差范围内选择最大的λ，得到更稀疏的模型，提升泛化能力。
   - 典型最优λ范围：A股因子筛选场景下 λ* ∈ [0.001, 0.1]。

2. **L-curve方法**：绘制 log||β||₁ vs log||Xβ-y||² 曲线，选取曲率最大点（拐点）对应的λ作为最优值。适用于噪声水平未知的场景。

3. **AIC/BIC信息准则法**：基于Akaike信息准则（AIC）或贝叶斯信息准则（BIC）选择λ，适用于样本量较大（N > 500）的场景。BIC倾向于选择更稀疏的模型。

**默认参数配置**：
- `alpha`（即λ）: 默认 0.01，范围 [1e-4, 10]
- `max_iter`: 1000（坐标下降法最大迭代次数）
- `tol`: 1e-4（收敛容差）
- `cv`: 5（交叉验证折数）
- `selection`: 'cyclic'（坐标选择策略）

### 变量说明表格

| 变量名 | 含义 | 类型 | 取值范围/典型值 |
|--------|------|------|-----------------|
| y | 因变量（未来收益率） | 数值 | [-0.5, 0.5]（月收益率） |
| X | 自变量矩阵（因子特征） | 数值矩阵 | 标准化后均值0、方差1 |
| β | 模型系数（因子权重） | 数值 | [-2, 2]，稀疏化后部分为0 |
| λ | L1正则化惩罚参数 | 数值 | [1e-4, 10]，默认0.01 |
| EMA | 指数移动平均 | 数值 | 股价量级（如10-2000） |
| DIF | MACD差离值 | 数值 | 股价量级±5% |
| Signal | MACD信号线 | 数值 | 股价量级±5% |

### 数值计算示例

```plaintext
股票代码：000001（平安银行）
日期：2021-01-01
PE：10      PB：1.2     ROE：15%     ROA：10%
MACD：0.1   Signal：-0.05

Lasso回归示例：
  输入：17个因子特征（PE/PB/ROE/ROA/营收增长/...）
  λ = 0.01（5折CV最优值）
  输出：β = [0, 0.15, 0.32, 0, 0.08, ...]（其中PE、ROA系数被压缩为0）
  保留因子：PB(0.15)、ROE(0.32)、营收增长(0.08)
  预测月收益率：ŷ = 0.15×1.2 + 0.32×0.15 + 0.08×0.2 = 0.232（即23.2%）
```

### 公式适用条件和局限性说明

1. **Lasso回归**：适用于高维特征选择场景（因子数 > 样本数时尤为有效），通过L1惩罚实现稀疏化，自动剔除冗余因子。局限性：当因子间存在高度共线性时，Lasso倾向于随机保留其中一个因子；此时建议结合Elastic Net（L1+L2混合正则化，l1_ratio=0.5）使用。λ值选择依赖交叉验证，小样本场景下CV误差较大，建议使用Bootstrap重采样增强稳定性。
2. **MACD计算**：适用于趋势分析和交易信号生成，但需要结合其他指标进行综合判断。局限性：MACD为滞后指标，在震荡市中容易产生虚假信号，建议配合RSI或Bollinger Bands过滤。

# 公式1：因子权重计算公式
W = (Σ(α_i * F_i)) / Σ(α_i)
```

| 变量名 | 含义 | 类型 | 取值范围 |
|--------|------|------|----------|
| W | 因子权重 | 数值 | 0-1 |
| α_i | 因子重要性系数 | 数值 | 0-1 |
| F_i | 因子值 | 数值 | 0-1 |

数值计算示例：
假设有两个因子，因子重要性系数分别为0.6和0.4，因子值分别为0.8和0.5，则因子权重计算如下：

W = (0.6 * 0.8 + 0.4 * 0.5) / (0.6 + 0.4) = 0.64

# 公式2：风险控制公式
R = (Σ(β_i * R_i)) / Σ(β_i)
```

| 变量名 | 含义 | 类型 | 取值范围 |
|--------|------|------|----------|
| R | 风险值 | 数值 | 0-1 |
| β_i | 风险重要性系数 | 数值 | 0-1 |
| R_i | 风险指标值 | 数值 | 0-1 |

数值计算示例：

R = (0.6 * 0.8 + 0.4 * 0.5) / (0.6 + 0.4) = 0.64

公式适用条件：适用于多因子选股模型，需要根据实际情况调整因子重要性系数和风险重要性系数。局限性：公式计算结果受因子重要性系数和风险重要性系数的影响较大。
