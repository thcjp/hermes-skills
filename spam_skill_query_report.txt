【综合结论 - 垃圾 Skill 识别】
1. 主要垃圾特征: trace_llm=20 (远低于 pass_threshold=42) 的自动删除 skill, 共 908 个
   (查询1), 它们多为差异化生成的 free/pro 版本 (parent_slug 非空, source_slug 为空)。
2. 全库 3408 个 skill 中, 2550 个 (74.8%) 处于 deleted/deleted_on_skillhub 状态 (查询4)。
3. trace_llm<45 的 2432 个 skill 中, deleted(915)+deleted_on_skillhub(896)=1811 个已删除,
   但仍有 75 个 active + 64 个 differentiated + 85 个 synced_from_skillhub + 391 local_only
   等低分 skill 未被删除, 可作为进一步清理候选。
4. body_missing / no_dir 删除标识在当前数据库中不存在; 实际删除原因为
   "trace_llm=20 低分自动删除" 与 "垃圾硬删除"。
5. 699 个有 source_slug 的 deleted skill 中, 271 个 (38.8%) 仍保留 parent_slug 关联,
   说明其差异化父版本仍存在, 删除时未级联清理父子关系。
