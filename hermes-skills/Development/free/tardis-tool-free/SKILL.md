# 生活事件追踪 - 免费版

## 概述

生活事件追踪工具免费版帮助个人用户记录与回顾生活中的重要事件。提供三种记录模式,从简单的要点记录到详细的故事叙述,灵活适配不同场景。所有数据存储在本地,保护隐私。

## 核心能力

### 1. 三种记录模式

- 简单模式:一句话记录事件
- 详细模式:结构化记录(时间/地点/人物/感受)
- 故事模式:自由叙述完整故事

**输出**: 返回三种记录模式的执行结果,包含操作状态和输出数据。

### 2. 事件分类

按类别(工作/生活/学习/旅行/健康)分类管理事件。

**输出**: 返回事件分类的执行结果,包含操作状态和输出数据。

- 执行此能力时使用`input_params`参数,支持创建/查询/导出操作
### 3. 标签系统

为事件添加自定义标签,便于后续检索。

**输出**: 返回标签系统的执行结果,包含操作状态和输出数据。

- 执行此能力时使用`input_params`参数,支持创建/查询/导出操作
### 4. 时间线回顾

按时间顺序回顾事件,支持按月/季/年查看。

**输出**: 返回时间线回顾的执行结果,包含操作状态和输出数据。

- 执行此能力时使用`input_params`参数,支持创建/查询/导出操作
### 5. 关键词搜索

全文搜索历史事件,快速定位记录。

**输出**: 返回关键词搜索的执行结果,包含操作状态和输出数据。

- 执行此能力时使用`input_params`参数,支持创建/查询/导出操作
### 6. 数据导出

导出为 Markdown 报告,便于分享与归档。

**输出**: 返回数据导出的执行结果,包含操作状态和输出数据。
**技术参数**：使用`input_params`和`output_format`参数控制执行行为,支持`json`/`text`/`csv`输出格式。
**能力覆盖范围**：本skill的核心能力覆盖以下场景关键词：个人生活事件追踪、支持三种模式记录、与回顾、适合个人时间管理、工具免费版、面向个人用户的时、间记录与回顾等。这些关键词对应description中声明的使用场景,均已在上述能力点中提供对应的操作支持。

## 使用场景

### 场景一:记录工作里程碑

使用详细模式记录工作中的重要事件。

```bash
# 记录事件(详细模式)
python3 tardis.py add \
  --mode detailed \
  --category "工作" \
  --title "项目上线" \
  --date "2025-01-15" \
  --location "公司" \
  --people "团队全员" \
  --feeling "兴奋且疲惫" \
  --details "经过3个月开发,核心项目终于上线。团队通宵部署,早上8点正式发布。"

# 输出:
# 事件已记录
# ID: evt-2025-0015
# 标题: 项目上线
# 日期: 2025-01-15
# 类别: 工作
```

### 场景二:简单模式快速记录

用简单模式快速记录日常事件。

```bash
# 快速记录
python3 tardis.py add \
  --mode simple \
  --category "生活" \
  --title "学会了做红烧肉" \
  --tags "烹饪,新技能"

# 批量快速记录
python3 tardis.py batch-add \
  --file events.txt \
  --mode simple

# events.txt 格式:
# 2025-01-15|生活|学会了做红烧肉|烹饪,新技能
# 2025-01-16|健康|跑步5公里|运动
# 2025-01-17|学习|读完《深入理解计算机系统》|阅读
```

### 场景三:时间线回顾

按时间线回顾过去的事件。

```bash
# 查看本月时间线
python3 tardis.py timeline \
  --period "2025-01" \
  --category "all"

# 输出:
# === 2025年1月时间线 ===
# 01-03 [工作] 新年领先个工作日,制定年度计划
# 01-08 [学习] 开始学习 Rust 语言
# 01-10 [生活] 和朋友聚餐,庆祝生日
# 01-15 [工作] 核心项目上线
# 01-20 [健康] 坚持跑步两周,体重减2kg
# 01-25 [旅行] 周末去古镇一日游
# 01-31 [学习] Rust 学习完成基础部分

# 按类别筛选
python3 tardis.py timeline --period "2025-01" --category "学习"
```

## 优选实践

1. **及时记录**:事件发生后尽快记录,避免遗忘细节
2. **简单模式优先**:日常用简单模式快速记录,重要事件再用详细模式
3. **善用标签**:标签是检索的关键,养成添加标签的习惯
4. **定期回顾**:每周/每月回顾时间线,总结与反思
5. **数据备份:定期导出数据,防止数据丢失
6. **隐私保护:本地存储确保隐私,不要将敏感记录同步到云端

## 常见问题

### Q: 数据存储在哪里?

A: 免费版数据存储在本地文件系统(默认 `~/tardis-data/`)。使用 JSON 格式,便于备份与迁移。不会上传到任何云端。

### Q: 可以在手机上使用吗?

A: 免费版是命令行工具,需要通过终端使用。可以通过 SSH 连接电脑使用,或使用 PRO 版的 Web 界面在手机浏览器访问。

### Q: 数据多了会变慢吗?

A: JSON 格式在数千条记录时仍能快速搜索。超过 1 万条建议按年分文件存储。免费版支持按年归档旧数据。

### Q: 可以导入其他日记应用的数据吗?

A: 免费版支持导入 CSV 格式数据。将其他应用的数据导出为 CSV,使用 `tardis.py import --format csv --file data.csv` 导入。
