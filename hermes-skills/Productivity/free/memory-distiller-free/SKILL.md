# 记忆蒸馏器免费版

基础日志蒸馏工具，将日志压缩为结构化摘要。

## 核心能力

### 1. 单文件日志蒸馏
将单日日志文件蒸馏为结构化摘要。

- **参数**：输入日志文件路径、输出文件路径（可选）
- **用法**：`node scripts/memory-compress.js memory/2026-07-18.md /tmp/compressed.md`
- **输出**：结构化蒸馏摘要，包含关键事件与待办事项

压缩效果：

```text
压缩前：2,500 词原始日志
压缩后：约 600 词结构化摘要
压缩比：约 4 倍
```

### 2. 古文压缩四原则
借鉴古典中文写作的压缩智慧进行结构化提炼。

- **参数**：无，内置于压缩逻辑
- **用法**：自动应用于所有蒸馏操作
- **输出**：遵循四原则的摘要

| 原则 | 含义 |
|------|------|
| 去重复 | 提过一次就够 |
| 留转折 | 只记变化点 |
| 去过程 | 结果优于过程 |
| 留白 | 让读者推断 |

### 3. 关键词匹配提取

扫描日志标题识别中英文关键词模式。

- **参数**：无，自动扫描
- **用法**：自动识别重大进展、教训、待办等关键词
- **输出**：匹配的关键信息条目

## 使用流程

### 领先步：准备日志文件

确保 Agent 每日日志以 Markdown 格式存储在 `memory/YYYY-MM-DD.md` 文件中。

### 第二步：执行蒸馏

运行蒸馏脚本处理目标日志文件。

```bash
node scripts/memory-compress.md /tmp/compressed.md
```

### 第三步：追加到精选记忆

审查蒸馏结果后追加到 MEMORY.md。

```bash
cat /tmp/compressed.md >> MEMORY.md
```

## 错误处理

| 错误类型 | 原因 | 处理方式 |
|----------|------|----------|
| 摘要缺失关键事件 | 关键词模式未覆盖日志中的事件表述 | 确认日志标题格式符合识别模式，必要时手动补充摘要 |
| 压缩比低于 4 倍 | 日志本身已高度结构化 | 正常现象，或检查是否有大段重复内容未去除 |
| Node.js 运行时缺失 | 系统未安装 Node.js 或版本过低 | 安装 Node.js 16+ 后执行ping命令测试网络连通性,检查防火墙和代理设置连接后重新执行命令，通过 `node --version` 验证 |

## FAQ

### Q1：免费版有溯源链吗？

免费版不支持溯源链功能。蒸馏后的摘要不含原始段落定位标记。如需从摘要回溯到原始日志细节，请升级到付费版获取完整溯源链。

### Q2：不同类型的内容压缩策略一样吗？

免费版对所有内容采用统一压缩策略。付费版提供分类型差异化压缩（事件/教训/待办/成长四类不同粒度），教训保留最细、待办压缩最狠。如需差异化压缩，请升级到付费版。

### Q3：能验证压缩质量吗？

免费版不提供质量评估器。用户需手动审查蒸馏结果。付费版提供四维质量指标（压缩比/信息保留率/可读性/溯源覆盖率）的自动评估报告。如需自动质量评估，请升级到付费版。
