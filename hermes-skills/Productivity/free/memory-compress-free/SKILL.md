# 日志压缩器免费版

基础日志压缩工具，将日志压缩为结构化摘要。

## 核心能力

### 1. 单文件日志压缩
将单日日志文件压缩为结构化摘要。

- **参数**：输入日志文件路径、输出文件路径（可选）
- **用法**：`node scripts/memory-compress.js memory/2026-07-18.md /tmp/compressed.md`
- **输出**：结构化压缩摘要，包含关键事件与待办事项

压缩效果：

```text
压缩前：2,500 词原始日志
压缩后：约 600 词结构化摘要
压缩比：约 4 倍
```

### 2. 古文压缩四原则
借鉴古典中文写作的压缩智慧进行结构化提炼。

- **参数**：无，内置于压缩逻辑
- **用法**：自动应用于所有压缩操作
- **输出**：遵循四原则的摘要

| 原则 | 含义 |
|------|------|
| 去重复 | 提过一次就够 |
| 留转折 | 只记变化点 |
| 去过程 | 结果优于过程 |
| 留白 | 让读者推断 |

### 3. 关键词匹配提取

扫描日志标题识别中英文关键词模式。

- **参数**：无，自动扫描
- **用法**：自动识别重大进展、教训、待办等关键词
- **输出**：匹配的关键信息条目

## 使用流程

### 领先步：准备日志文件

确保 Agent 每日日志以 Markdown 格式存储在 `memory/YYYY-MM-DD.md` 文件中。

### 第二步：执行压缩

运行压缩脚本处理目标日志文件。

```bash
node scripts/memory-compress.md /tmp/compressed.md
```

### 第三步：追加到精选记忆

审查压缩结果后追加到 MEMORY.md。

```bash
cat /tmp/compressed.md >> MEMORY.md
```

## 错误处理

| 错误类型 | 原因 | 处理方式 |
|----------|------|----------|
| Node.js 运行时缺失 | 系统未安装 Node.js 或版本过低 | 安装 Node.js 16+ 后执行ping命令测试网络连通性,检查防火墙和代理设置连接后重新执行命令，通过 `node --version` 验证 |
| 输出目录不存在 | 指定的输出文件路径所在目录未创建 | 手动 `mkdir -p` 创建目录后执行ping命令测试网络连通性,检查防火墙和代理设置连接后重新执行命令 |
| 压缩比为 1（未压缩） | 日志本身已高度结构化 | 正常现象，无冗余可去除 |

## FAQ

### Q1：免费版支持批量压缩吗？

免费版仅支持单文件压缩。如需批量压缩多日日志，请升级到付费版。

### Q2：压缩比能达到多少？

免费版典型压缩比约 4 倍。付费版通过混合提取引擎可达 4-8 倍。压缩比取决于原始日志的冗余度。

### Q3：压缩会丢信息吗？

免费版使用关键词匹配提取，未匹配的章节可能遗漏。付费版的兜底提取机制确保零数据丢失。建议关键场景人工审查压缩结果。
