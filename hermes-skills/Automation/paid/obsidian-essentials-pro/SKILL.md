=========== 多设备同步配置 ===========
方案1：iCloud同步（Apple生态推荐）
适用：macOS + iOS用户
步骤：
1. 将vault创建在iCloud目录
   - macOS: ~/Library/Mobile Documents/com~apple~CloudDocs/MyVault
   - iOS: 通过iCloud Drive访问
2. 在每台设备上用Obsidian打开该vault
3. 自动同步，无需额外配置
方案2：Obsidian Sync（官方付费）
适用：跨平台、需要端到端加密
步骤：
1. 订阅Obsidian Sync服务
2. 设置 → 核心插件 → 启用"同步"
3. 创建同步仓库
4. 在每台设备连接同一同步仓库
优点：端到端加密、版本历史、选择性同步
方案3：Git版本控制（技术用户推荐）
适用：跨平台、需要版本控制
步骤：
1. 在vault初始化Git
   cd ~/Documents/MyVault
   git init
   git remote add origin <repository-url>
2. 创建.gitignore
   .obsidian/workspace.json
   .obsidian/workspace-mobile.json

4. 配置自动提交与推送

1. 安装Syncthing
